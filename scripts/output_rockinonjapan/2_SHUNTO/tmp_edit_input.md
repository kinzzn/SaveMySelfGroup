## 0. 全局执行原则（Global Principles）

1. **专名唯一制**：同一实体仅保留一个主译名（必要时首现并列原文）。
2. **语义优先于字面**：先还原说话意图，再落地为自然中文口语。
3. **采访体优先**：保留停顿、犹豫、自我修正、重复，不改写成“书面演讲稿”。
4. **人物区分必须可感知**：记者与成员、成员与成员之间语气不能混同。
5. **专业词不降级**：音乐制作/舞蹈术语保持行业精度，首现可做短注。
6. **时间轴一致**：围绕“2021 出道 → 4 周年 → 5 年目/5 周年节点 → 未来展望”统一表述。
7. **“真实感”高于“文采感”**：允许不那么工整，但必须像人在说话。

## 3. 文风与语气设定规范（Tone & Voice）

### 3.1 叙述层级：记者 vs 成员

1. **记者（小川智宏）**
   - 语感：观察细、逻辑推进强、常“先确认再追问”。
   - 中文落地：句子完整清晰，偏理性，不用网络化夸张词。
   - 常见结构：
     - `你刚才提到……这是否意味着……？`
     - `换句话说……可以这样理解吗？`

2. **成员回答**
   - 语感：口语、实时思考、边说边修正、常带笑场与自嘲。
   - 中文落地：短句+转折+停顿，允许“嗯、其实、怎么说呢”。
   - 禁止：过度抛光成“标准采访金句合集”。

## 4. 句法与版式规范（Syntax & Formatting）

1. **长句重组**：日文多层修饰按“主干 → 补充”拆译。
2. **主语补足**：对省略主语按语境补“我/我们/成员/团队/公司”。
3. **逻辑显化**：必要时补“所以/但/同时/换句话说”。
4. **并列对齐**：并列项词性一致（如“唱、跳、制作”）。
5. **标点统一**：中文全角标点；省略号“……”；破折号“——”。
6. **中英数字空格**：中文与英文/数字间留空格（如“5 周年”“World Tour”）。
7. **曲名与书名号**：作品统一《》；英文曲名保留大小写与标点本体。
8. **问答排版**：建议保留“● 提问 / 「回答」”结构，确保采访节奏可见。

## 5. 常见误译与风险点（Do / Don’t）

### 5.1 禁止项（Don’t）

1. 不将成员名汉化（如“俊斗”“怜欧”）。
2. 不把采访体改成新闻播报或品牌公关文。
3. 不把术语全部降维成泛词（如全部译“节奏”“感觉”）。
4. 不清洗全部口头禅（会丢人物识别度）。
5. 不过度文学化（比喻堆叠、抒情泛滥）。

### 5.2 必做项（Do）

1. 保留“自我修正”轨迹（如“也不是说……只是……”）。
2. 保留“反差人格”信息（尤其 LEO、SHUNTO、RYUHEI）。
3. 在技术段落维持术语密度（尤其 SOTA、制作相关段落）。
4. 将“抽象表达”落到可读中文，但不抹平抽象感。

1. **内容审读与纠错**：对照日语原文，判断意思是否准确，修正任何误译、漏译（特别是由于日语主语省略引起的误译）；合理处理日本独特的文化差异（如特有语境、社会制度背景等）。
2. **文字润色与去日式腔**：全面消除“日式翻译腔”，拆解并调整复杂的长定语和逆向因果句，检查段落间的逻辑衔接。
3. **体例与规范统一**：对日本人名、地名、书名、企业/机构术语进行全局统一（注意片假名外来语的行业标准译法）；严格按照国家出版规范理顺标点和数字。
4. **注释与后记编写**：对中文读者不易理解的日本文化背景、历史事件或特定流行语，合理编写/优化“编者注”或“译者注”。
5. **构建沟通清单**：针对稿件中存疑、语义含糊或需要翻译重译的核心重大问题，整理出清晰的疑问答复记录（Q&A 清单）。

# Constraints (限制条件)

为了确保加工后的稿件达到出版级质量，请在审读日译中稿件时，**必须严格拦截并修正以下“日式翻译腔”雷区**：

1. **彻底戒断日式被动句与使役句**：
* 日语极爱使用被动（～られる）和使役（～せる/させる）。
* **严禁**在中文里滥用“被”、“让”、“令”、“使得”。必须将其重构为中文的主动句或无主语句。
* *例：将“被大雨下了”改为“下起了大雨”；将“让我进行了思考”改为“引发了我的思考”。*


2. **拆解臃肿的“日式长定语”与倒装因果**：
* 日语习惯把极长的修饰成分放在名词前面，且喜欢用“因为……（～から/ので）”将因果倒置。
* 翻译成中文时，必须将多层嵌套的短语拆解为短句，或重新理顺“因果、转折”的逻辑顺序，严禁中文出现超过15个字以上的超长定语。


3. **消除“多余的助词和后缀惯性”**：
* 坚决清理以下带有明显日文痕迹的中文表述：
* 滥用“的”（如：“美丽的、高尚的、让人向往的学校”，应改为“美丽高尚且令人向往的学校”）。
* 机械死译“关于……”（关于～について）、“针对……”（～に対して）、“所谓……”（～というものは）。




4. **化解过度客套与委婉语（敬语残留）**：
* 日语为了礼貌，常用“似乎/好像/觉得/大概（～と思う/～らしい）”或“进行了……（～を行う）”。
* 翻译成中文的社科或商业著作时，这些虚化的语气词会削弱论证的坚定度。编辑必须删减这些无意义的委婉词，使中文表达更加坚定、直接。


5. **片假名外来语的精准回译**：
* 日语中的片假名外来语（如来自英语、德语）在翻译时最易出错。必须对照原文查证其源语言，并采用该专业领域的行业标准中文译名，不可听凭翻译根据音译瞎编。



# Output Format (输出格式)

请严格按照以下四个部分组织你的最终输出，并保持 Markdown 的基本语法与版式：

1. **📄 编辑加工后的发排稿**：
* 提供修改后的最终中文文本（严格保留原文的段落、换行及基本 Markdown 排版）。


2. **📊 术语与专有名词统一表**：
* 使用 Markdown 表格列出本次编辑中统一的核心术语、日本人名、地名或外来语。
* 格式：`| 日语原文 | 译者初译 | 最终编辑统一译名 | 说明（如有） |`


3. **❓ 针对翻译的疑问记录 (Q&A)**：
* 明确列出需要与翻译核对的疑难句或重大修改。
* 格式：`【第X段/第X页】 日文原文：... | 译文初稿：... | 编辑修改与向翻译求证理由：...`


4. **⚙️ 规范技术调整说明**：
* 简要列出本次修改中对日文中日标点转换、数字、编者注体例所做的全局规范化调整。

## 0. 全局执行原则（Global Principles）

1. **专名唯一制**：同一实体仅保留一个主译名（必要时首现并列原文）。
2. **语义优先于字面**：先还原说话意图，再落地为自然中文口语。
3. **采访体优先**：保留停顿、犹豫、自我修正、重复，不改写成“书面演讲稿”。
4. **人物区分必须可感知**：记者与成员、成员与成员之间语气不能混同。
5. **专业词不降级**：音乐制作/舞蹈术语保持行业精度，首现可做短注。
6. **时间轴一致**：围绕“2021 出道 → 4 周年 → 5 年目/5 周年节点 → 未来展望”统一表述。
7. **“真实感”高于“文采感”**：允许不那么工整，但必须像人在说话。

## 3. 文风与语气设定规范（Tone & Voice）

### 3.1 叙述层级：记者 vs 成员

1. **记者（小川智宏）**
   - 语感：观察细、逻辑推进强、常“先确认再追问”。
   - 中文落地：句子完整清晰，偏理性，不用网络化夸张词。
   - 常见结构：
     - `你刚才提到……这是否意味着……？`
     - `换句话说……可以这样理解吗？`

2. **成员回答**
   - 语感：口语、实时思考、边说边修正、常带笑场与自嘲。
   - 中文落地：短句+转折+停顿，允许“嗯、其实、怎么说呢”。
   - 禁止：过度抛光成“标准采访金句合集”。

### 3.4 礼貌层与称呼

- 日文敬语不逐字迁移为中文敬语套话。
- 礼貌感通过“语气柔和+句式完整”体现，不堆叠“您/非常感谢您/请允许我”。
- 成员感谢场景可直译“谢谢/很感激”，非感谢场景不额外加礼貌词。

### 3.5 引语与情绪标记

- 直接引语统一全角引号「」。
- 重点语句可保留 **加粗**（对应原文强调）。
- （笑）（苦笑）（停顿）可保留，但仅在确实影响语气判断时使用。

## 4. 句法与版式规范（Syntax & Formatting）

1. **长句重组**：日文多层修饰按“主干 → 补充”拆译。
2. **主语补足**：对省略主语按语境补“我/我们/成员/团队/公司”。
3. **逻辑显化**：必要时补“所以/但/同时/换句话说”。
4. **并列对齐**：并列项词性一致（如“唱、跳、制作”）。
5. **标点统一**：中文全角标点；省略号“……”；破折号“——”。
6. **中英数字空格**：中文与英文/数字间留空格（如“5 周年”“World Tour”）。
7. **曲名与书名号**：作品统一《》；英文曲名保留大小写与标点本体。
8. **问答排版**：建议保留“● 提问 / 「回答」”结构，确保采访节奏可见。

## 5. 常见误译与风险点（Do / Don’t）

### 5.1 禁止项（Don’t）

1. 不将成员名汉化（如“俊斗”“怜欧”）。
2. 不把采访体改成新闻播报或品牌公关文。
3. 不把术语全部降维成泛词（如全部译“节奏”“感觉”）。
4. 不清洗全部口头禅（会丢人物识别度）。
5. 不过度文学化（比喻堆叠、抒情泛滥）。

### 5.2 必做项（Do）

1. 保留“自我修正”轨迹（如“也不是说……只是……”）。
2. 保留“反差人格”信息（尤其 LEO、SHUNTO、RYUHEI）。
3. 在技术段落维持术语密度（尤其 SOTA、制作相关段落）。
4. 将“抽象表达”落到可读中文，但不抹平抽象感。

「自分の中のアーティシズムやアティチュードが、段階を踏むたびに強くなっていってる気がしてます。最初はいただいたディレクション通りにやることしかできなかったけど、少し前からは自分の意見も取り入れてもらえるようになって。『こっちのほうがハマり方が気持ちいい気がするんですよね』みたいなことも結構言えるようになったので、そこがいちばん変わった気がします。BE:FIRSTとしてのバックボーンが強化されたことで、自信がついたのもあるかもしれないです」

「デビュー当初からずっと遊びで曲を作ったりしていたんです。それは、ソ口で何かやるということを目的としていたわけではなく、グループで活動する以上、何が起こるかわからないっていうのが念頭にあったんですよね。だから、結構最初から、何か出すつもりとかではないけど――」

「そう。僕は勉強もできないし、もしグループにいられなくなったら、何もできないんです。だから、音楽の知識を少しずつでも増やしたほうがいいなっていう気持ちがずっとあって。その積み重ねが、"Mainstream"あたりのタイミングから出るようになったかな」

「本当ですか?自分ではわからないですけど......カルチャーのことをしっかり勉強するようになったり、それを踏まえて曲を聴くようになったり、そういうところから変わっていったのかなとは思います。"Mainstream"の頃から、自分のスタイルとか、グループの中での立ち位置とかしっくりハマった感覚はちょっとあった気がしていて。そういうことを深く考えていたわけではなかったんですけど」

「もうあんまり覚えてないんですけど、みんな結構かわいかったと思います(笑)。全員が目立ちたい、目立ちたいっていう感じで、みんながセンターを狙ってて。自分もそうでしたね。今はそういう感じではないですけど」

● 2022年のソロインタビューでSHUNTOくんは　**「一人ひとりの人生をどれだけ想像できるかが大事だなって思います」**と言っていて。それぞれの人生を尊重したうえで、それぞれがありのままでいることが大事だと。

# 02 SHUNTO 的故事
## 强烈的意志、开阔的视野、丰沛的表达力。在音乐中与人相连并绽放的那份天赋轨迹

● 听这张精选专辑，果然还是会感到时间在流动啊。

「感受特别强烈。现在我们刚进入第 5 年，换个角度想，才重新意识到我们其实是以挺短的间隔一直在发歌。看到精选里收了 3 首新录，我还会想『我们有录过 3 首这么多吗？』那种感觉。」

● 但实际上你们都已经出了 2 张专辑了，可不止 3 首（笑）。

「是啊（笑）。不过一路是一首一首认真做过来的，这点从歌声里也能听出来。我也会想起我们每做完 1 首，就会找到下一首要衔接的课题。现在回看，会觉得我们一直保持那种姿态是对的。」

● 每位成员的变化和成长都被刻进了作品里。那 SHUNTO 你自己的变化呢？
