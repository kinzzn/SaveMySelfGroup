# Constraints (限制条件)

为了确保加工后的稿件达到出版级质量，请在审读日译中稿件时，**必须严格拦截并修正以下“日式翻译腔”雷区**：

1. **彻底戒断日式被动句与使役句**：
* 日语极爱使用被动（～られる）和使役（～せる/させる）。
* **严禁**在中文里滥用“被”、“让”、“令”、“使得”。必须将其重构为中文的主动句或无主语句。
* *例：将“被大雨下了”改为“下起了大雨”；将“让我进行了思考”改为“引发了我的思考”。*


2. **拆解臃肿的“日式长定语”与倒装因果**：
* 日语习惯把极长的修饰成分放在名词前面，且喜欢用“因为……（～から/ので）”将因果倒置。
* 翻译成中文时，必须将多层嵌套的短语拆解为短句，或重新理顺“因果、转折”的逻辑顺序，严禁中文出现超过15个字以上的超长定语。


3. **消除“多余的助词和后缀惯性”**：
* 坚决清理以下带有明显日文痕迹的中文表述：
* 滥用“的”（如：“美丽的、高尚的、让人向往的学校”，应改为“美丽高尚且令人向往的学校”）。
* 机械死译“关于……”（关于～について）、“针对……”（～に対して）、“所谓……”（～というものは）。




4. **化解过度客套与委婉语（敬语残留）**：
* 日语为了礼貌，常用“似乎/好像/觉得/大概（～と思う/～らしい）”或“进行了……（～を行う）”。
* 翻译成中文的社科或商业著作时，这些虚化的语气词会削弱论证的坚定度。编辑必须删减这些无意义的委婉词，使中文表达更加坚定、直接。


5. **片假名外来语的精准回译**：
* 日语中的片假名外来语（如来自英语、德语）在翻译时最易出错。必须对照原文查证其源语言，并采用该专业领域的行业标准中文译名，不可听凭翻译根据音译瞎编。

# 四、专有名词的翻译原则

## 4.1 英文名称

1. 公司、厂牌、组合、艺名、节目名、歌曲名原则上保留英文。
2. 保留官方大小写、冒号、连字符、句号、撇号及特殊符号。

5. `feat.`、`BMSG`、`CEO`、`MC`、`D.U.N.K.`等行业惯用缩写保留原文和标点。

## 4.2 作品名与活动名

- 书籍、文章、节目、电影、专辑、单曲、舞台剧：使用中文书名号《》。

## 4.3 人名

1. 艺名优先保留官方拼写。
2. 日本姓名采用官方通行中文译名；无法确认时不擅自创造汉字译名。

# 五、文体与叙事结构规范

## 5.1 总体文风

本书中文应呈现以下综合特征：

- **出版报道体**：准确、清楚、结构严谨。
- **人物访谈体**：保留说话者的停顿、反问、转折与自我修正。
- **管理学表达**：概念明确，避免空泛鸡汤。
- **音乐行业语境**：熟悉现场、制作、发行、艺人管理等专业表达。
- **艺术家口吻**：保留热情、想象力、感性与偶尔的夸张。
- **第一人称真实性**：不得把口语润色成冷冰冰的书面报告。
- **第三人称客观性**：记者叙述应克制，不替人物下结论。

## 5.2 第三人称报道部分

### 基本特征

第三人称部分通常由记者撰写，具有以下特点：

- 事实密度高；
- 时间、地点、作品、成绩交代清楚；
- 适度评价舞台与组织发展；
- 常用“……的意义在于”“……可以说是……”等分析句；
- 语气客观，但不完全冷峻；
- 会通过现场观察表现人物状态。

### 中文处理规范

1. 句子可以适当拆分，避免日文长句堆叠。
2. 事实信息不得遗漏：
   - 日期；
   - 演出地点；
   - 公演数量；
   - 参与艺人；
   - 发行时间；
   - 榜单成绩；
   - 项目关系。
3. 日文中的“〜と言っても過言ではない”统一处理为：
   - “称其为……并不为过”
   - “可以说……并不夸张”
4. 日文中的“〜ように思えた”可译为：
   - “让人感到……”
   - “似乎……”
   - “给人留下了……的印象”
5. 避免将记者观察写成绝对判断。
6. “大きく動いた”根据语境译为“迎来重要进展”“发生重大变化”，不译为“动得很大”。
7. “快進撃”统一优先译为“强劲发展势头”“高歌猛进”，避免过度军事化。
8. “圧巻”可译为“震撼”“气势十足”“令人叹为观止”，根据上下文选择。
9. “堂々たる姿”统一优先译为“从容而自信的姿态”或“气场十足的表现”。

## 5.3 SKY-HI／日高光启的第一人称发言

### 人物基调

SKY-HI的语言同时具有以下层次：

1. **经营者的理性**
   - 重视结构、机制、可持续性、组织成长；
   - 会明确区分“梦想”“目标”“里程碑”“必达条件”；
   - 习惯从产业、公司与长期愿景的角度思考。

2. **艺术家的感性**
   - 重视音乐、身体性、情绪、氛围、直觉；
   - 常用“喜欢就是喜欢”“让人心动”“幸福”等表达；
   - 具有强烈的现场感和想象力。

3. **创业者的行动力**
   - 频繁使用“要做”“必须做”“不做就不会改变”等句式；
   - 对行业问题直言不讳；
   - 语气有时热烈、急切，带有自我驱动感。

4. **平等、亲近的沟通方式**
   - 不摆出高高在上的社长姿态；
   - 对艺人、员工、粉丝、合作伙伴多使用尊重和感谢；
   - 经常以“我也……”进行自我反省或自我定位。

5. **幽默与自嘲**
   - `妄信もあります（笑）`等表达应保留轻松感；
   - `奇特な人生ですね`可译为“真是段奇特的人生”；
   - 笑声、停顿、补充说明不宜全部删除。

### 中文语气规范

- 使用自然的现代中文口语，但避免网络化、低俗化。
- 可以使用“其实”“我觉得”“确实”“说到底”“当然”等口语连接词。
- 不把所有发言改成正式演讲稿。
- 不将“〜ですよね”机械翻译为“对吧”；根据语气可译为：
  - “确实如此。”
  - “我也是这么觉得的。”
  - “……不是吗？”
  - “说到底，……”
- 不将“〜じゃないですか”全部译为反问；可能是强调、确认或自我解释。
- `〜なんですよね`可译为：
  - “其实是……”
  - “……就是这么回事。”
  - “我当时确实……”
- `〜と思います`根据确定程度译为“我认为”“我觉得”“我想”。
- `〜かなと思っています`应保留谨慎感，可译为“我想……”“我倾向于认为……”。
- `本当に`不可每次都译为“真的”；可根据语气处理为“确实”“非常”“实在是”“说实话”。

## 5.4 记者提问部分

记者的提问具有以下特点：

- 礼貌、清晰、层层推进；
- 通常先介绍事实，再提出问题；
- 会引用受访者过去说过的话；
- 可能使用较长的铺垫；

### 中文处理原则

- 正式采访中使用“您”。
- 提问应自然、准确，不刻意模仿日语敬语层级。
- `〜について改めて聞いた`统一优先译为：
  - “我们再次请他谈了谈……”
  - “这次，我们首先请他回顾……”
- `〜ということだろうか`可译为：
  - “这意味着什么？”
  - “应该如何理解？”
  - “究竟是出于怎样的考虑？”
- 采访者对SKY-HI的称呼统一为“SKY-HI先生”或“SKY-HI”，全书须择一。正文叙述中优先使用“SKY-HI”。

# 十、翻译禁忌

## 10.1 不得过度文学化

不得将管理、采访、行业表达改写成散文式抒情文字。例如：

- `会社を動かす仕組み`  
  不译为“让公司焕发生命力的齿轮”  
  应译为“推动公司运转的机制”。

- `空気感がいい`  
  不译为“空气中流淌着明媚的光”  
  应译为“整体氛围很好”。

## 10.2 不得网络化

避免以下表达：

- 炸裂；
- 爆杀；
- 杀疯了；
- 天花板；
- 封神；
- 破防；
- 内卷；
- 油管；
- 男团／女团。

除非原文明确使用相同强度的网络或流行表达，否则采用出版体。

## 10.3 不得擅自拔高或削弱

- `変えたい`可译为“想改变”，不自动改成“颠覆”。
- `大きな夢`可译为“大梦想”，不自动改成“宏伟蓝图”。
- `楽しい`可译为“开心”“愉快”，不自动改成“狂欢”。
- `強い意志`可译为“坚定意志”，不自动改成“革命决心”。
- `救世主`应保留为“救世主”，但不替作者增加宗教或政治色彩。

## 10.4 不得消除矛盾与犹豫

SKY-HI的发言中常有：

- “我觉得……”
- “可能是……”
- “其实我也……”
- “说实话……”
- 自我修正；
- 先肯定、后保留；
- 一边兴奋、一边担忧。

这些并非赘词，而是人物思考过程的重要组成部分，不得为追求简洁而全部删去。

2012年我创立「BULLMOOSE」时，其实已经有了将来创办「BMS」「BMSG」这家公司的愿景。2020年真正成立「BMSG」时，我就感觉「BULLMOOSE」已经作为 BMSG 的前身，成为这段历史中的一块拼图。不过，如今再次冠以这个名字，似乎也挺有意思。我这么想。Shota 也说“Bullmoose 最好”，所以我下定决心重新启用雄性驼鹿（bullmoose）的设计，并委托 Nozle Graphics 设计标志。其实在之前的 BULLMOOSE 时期，我也曾与他有过一点合作，因此他对这个名字重新启用感到非常高兴，这也让我很开心。

### 打造一档比想象中有趣5亿倍的节目

**在“企业发布会”视频的 Bullmoose 部分，SKY-HI 还用英语进行了演讲，希望将信息传递到海外。2024年1月接受采访时，他曾透露，2024年将推进由个人艺人联合组成的项目，并预感这一活动或许会具备走向海外的可能性。那么，如今 Bullmoose 实际启动后，他又是怎样想的呢？**

目前这还只不过是“创办一项新业务”，前提是今后可能进行 pivot（业务转型）。根据情况，Bullmoose 要做的事情也可能发生各种变化。首先，我们希望通过第一弹作品 BMSG POSSE，扎扎实实做出很酷的作品，展示给社会大众。发布会上提到的、为艺人独立发展提供支持的定制化合作协议，以及海外拓展，也可能是在展示 BMSG POSSE 的活动成果之后逐步产生的。

**另一个令人关注的进展，是 BMSG 与 Chanmina 携手推进的女子组合选秀企划「No No Girls」。发布会上公布，第一组女子组合将在2024年内出道（之后出道时间改为2025年），并表达了对这一组合的厚望：“我相信，一定会诞生一个推动时代、改变历史的组合。”**

我觉得，真的会发生不得了的事情。首先，我认为，BE:FIRST 的诞生之所以受到社会大众期待，其中一个原因就是大家单纯地想看到一支舞蹈和歌唱水平都很高的组合。当然，韩国组合出色的技能水平，以及他们在全球范围内的影响力，也是这一背景的一部分。日本也能有一支在实力层面与之竞争的组合——这种潜在愿望，与 BE:FIRST 的诞生结合在了一起，这一点或许非常重要。

不过，等到「No No Girls」以及由此出道的组合登场时，它们给社会带来的冲击可能还会更大。除了歌唱、舞蹈和说唱的高水准之外，我感到，社会对于拥有强烈态度、立场和意志的女性登场的期待，或许比男性领域强烈得多。因此，我认为新组合的诞生将会在这一领域引发一场革命。

话虽如此，我在这次选秀中做的事情，就是听 Chanmina 说话，有时给她买些好吃的巧克力，累了就帮她按摩头部（笑）。不过，包括淘汰等决定及通知在内，今后也都将由她亲自完成，接下来她会持续面对充满压力、承受巨大负担的日子。到了那种时候，坚定地站在她身后，发挥导师一样的作用，就是我这次的工作。等节目在年内播出时，它会比大家想象的有趣5亿倍（笑），敬请期待。
