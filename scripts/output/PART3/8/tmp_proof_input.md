# 四、专有名词的翻译原则

## 4.1 英文名称

1. 公司、厂牌、组合、艺名、节目名、歌曲名原则上保留英文。
2. 保留官方大小写、冒号、连字符、句号、撇号及特殊符号。
3. 首次出现时可根据读者理解需要添加中文说明，但不得每次重复。
4. 不将英文艺名强行意译。
5. `feat.`、`BMSG`、`CEO`、`MC`、`D.U.N.K.`等行业惯用缩写保留原文和标点。
6. 同一名称不得在不同章节分别译作中文或英文。

## 4.2 作品名与活动名

- 书籍、文章、节目、电影、专辑、单曲、舞台剧：使用中文书名号《》。
- 巡演、音乐节、公司项目及活动品牌：通常保留英文，不额外添加书名号。
- 作品名称内部已有引号、冒号、连字符时，保留原有格式。
- “D.U.N.K.”不得写成“DUNK”；“BE:FIRST”不得省略冒号。
- “BE:the ONE”中的冒号和大小写不得改动。
- “BE:1”与“2:BE”不得混淆。

## 4.3 人名

1. 艺名优先保留官方拼写。
2. 日本姓名采用官方通行中文译名；无法确认时不擅自创造汉字译名。
3. 人物昵称应保留亲密程度：
   - `コア`：只可译为“Core”。
   - `りょんりょん`：首次出现应说明为佐藤凉子的昵称。
4. 访谈中使用姓氏、名字或昵称时，必须保留原文的亲疏关系。
5. 不因中文表达习惯而擅自把所有人物改称全名。

# 五、文体与叙事结构规范

## 5.1 总体文风

本书中文应呈现以下综合特征：

- **出版报道体**：准确、清楚、结构严谨。
- **人物访谈体**：保留说话者的停顿、反问、转折与自我修正。
- **管理学表达**：概念明确，避免空泛鸡汤。
- **音乐行业语境**：熟悉现场、制作、发行、艺人管理等专业表达。
- **艺术家口吻**：保留热情、想象力、感性与偶尔的夸张。
- **第一人称真实性**：不得把口语润色成冷冰冰的书面报告。
- **第三人称客观性**：记者叙述应克制，不替人物下结论。

## 5.2 第三人称报道部分

### 基本特征

第三人称部分通常由记者撰写，具有以下特点：

- 事实密度高；
- 时间、地点、作品、成绩交代清楚；
- 适度评价舞台与组织发展；
- 常用“……的意义在于”“……可以说是……”等分析句；
- 语气客观，但不完全冷峻；
- 会通过现场观察表现人物状态。

### 中文处理规范

1. 句子可以适当拆分，避免日文长句堆叠。
2. 事实信息不得遗漏：
   - 日期；
   - 演出地点；
   - 公演数量；
   - 参与艺人；
   - 发行时间；
   - 榜单成绩；
   - 项目关系。
3. 日文中的“〜と言っても過言ではない”统一处理为：
   - “称其为……并不为过”
   - “可以说……并不夸张”
4. 日文中的“〜ように思えた”可译为：
   - “让人感到……”
   - “似乎……”
   - “给人留下了……的印象”
5. 避免将记者观察写成绝对判断。
6. “大きく動いた”根据语境译为“迎来重要进展”“发生重大变化”，不译为“动得很大”。
7. “快進撃”统一优先译为“强劲发展势头”“高歌猛进”，避免过度军事化。
8. “圧巻”可译为“震撼”“气势十足”“令人叹为观止”，根据上下文选择。
9. “堂々たる姿”统一优先译为“从容而自信的姿态”或“气场十足的表现”。

## 5.3 SKY-HI／日高光启的第一人称发言

### 人物基调

SKY-HI的语言同时具有以下层次：

1. **经营者的理性**

   - 重视音乐、身体性、情绪、氛围、直觉；
   - 常用“喜欢就是喜欢”“让人心动”“幸福”等表达；
   - 具有强烈的现场感和想象力。

3. **创业者的行动力**
   - 频繁使用“要做”“必须做”“不做就不会改变”等句式；
   - 对行业问题直言不讳；
   - 语气有时热烈、急切，带有自我驱动感。

4. **平等、亲近的沟通方式**
   - 不摆出高高在上的社长姿态；
   - 对艺人、员工、粉丝、合作伙伴多使用尊重和感谢；
   - 经常以“我也……”进行自我反省或自我定位。

5. **幽默与自嘲**
   - `妄信もあります（笑）`等表达应保留轻松感；
   - `奇特な人生ですね`可译为“真是段奇特的人生”；
   - 笑声、停顿、补充说明不宜全部删除。

### 中文语气规范

- 使用自然的现代中文口语，但避免网络化、低俗化。
- 可以使用“其实”“我觉得”“确实”“说到底”“当然”等口语连接词。
- 不把所有发言改成正式演讲稿。
- 不将“〜ですよね”机械翻译为“对吧”；根据语气可译为：
  - “确实如此。”
  - “我也是这么觉得的。”
  - “……不是吗？”
  - “说到底，……”
- 不将“〜じゃないですか”全部译为反问；可能是强调、确认或自我解释。
- `〜なんですよね`可译为：
  - “其实是……”
  - “……就是这么回事。”
  - “我当时确实……”
- `〜と思います`根据确定程度译为“我认为”“我觉得”“我想”。
- `〜かなと思っています`应保留谨慎感，可译为“我想……”“我倾向于认为……”。
- `本当に`不可每次都译为“真的”；可根据语气处理为“确实”“非常”“实在是”“说实话”。

## 7.1 “做自己”理念

## 7.2 “梦想”与“目标”

| 概念 | 统一区分 |
|---|---|
| 夢 | 梦想，具有超越现实限制的愿景 |
| 目標 | 目标，具有现实可执行性 |
| マイルストーン | 里程碑，为长期梦想服务的阶段性成果 |
| 必達条件 | 必须完成、不可退让的条件 |
| ビジョン | 愿景，关于未来整体方向的设想 |

推荐译法：

> “目标”能够放大实现可能之事的可能性；而“梦想”，则可能让不可能之事变为可能。

不得将“梦想”和“目标”混译。

# 十、翻译禁忌

## 10.1 不得过度文学化

不得将管理、采访、行业表达改写成散文式抒情文字。例如：

- `会社を動かす仕組み`  
  不译为“让公司焕发生命力的齿轮”  
  应译为“推动公司运转的机制”。

- `空気感がいい`  
  不译为“空气中流淌着明媚的光”  
  应译为“整体氛围很好”。

## 10.2 不得网络化

避免以下表达：

- 炸裂；
- 爆杀；
- 杀疯了；
- 天花板；
- 封神；
- 破防；
- 内卷；
- 油管；
- 男团／女团。

除非原文明确使用相同强度的网络或流行表达，否则采用出版体。

## 10.3 不得擅自拔高或削弱

- `変えたい`可译为“想改变”，不自动改成“颠覆”。
- `大きな夢`可译为“大梦想”，不自动改成“宏伟蓝图”。
- `楽しい`可译为“开心”“愉快”，不自动改成“狂欢”。
- `強い意志`可译为“坚定意志”，不自动改成“革命决心”。
- `救世主`应保留为“救世主”，但不替作者增加宗教或政治色彩。

## 10.4 不得消除矛盾与犹豫

SKY-HI的发言中常有：

- “我觉得……”
- “可能是……”
- “其实我也……”
- “说实话……”
- 自我修正；
- 先肯定、后保留；
- 一边兴奋、一边担忧。

这些并非赘词，而是人物思考过程的重要组成部分，不得为追求简洁而全部删去。

さらに「新鮮な風を起こしたい」という思いもありました。BMSG設立に始まり、BE:FIRSTを生んだオーディション「THE FIRST」の熱量、デビュー以降のBE:FIRSTの勢い、さらには“事務所の壁を超えた”プロジェクトである「D.U.N.K.」が始動した時期に、こうした一連の勢いを感じていただきたかった。BMSGは「勢い」がある状態でしたが、そうした「勢い」が加速するのは、「勢いがある」とたくさんの人に感じて、思っていただくことでもあるのです。

### 組織のマネジメント機能を強化

**G&Gに向けてBMSGがキーテーマに掲げたのは、「TYOISM(トウキョウイズム)」。起業以来、BMSGは「東京発」のカルチャーを発信することを掲げていた。今回のG&Gでは改めて「東京が持っている魅力、東京が育んできたカルチャーにリスペクトを示し、継承し、その東京を象徴する、東京から発信していくと改めて強調することが、BMSGらしい東京からのグローバリズムにつながる」とし、その名の下に「BMSG」の4つを頭文字として、「BASE」「MASS APPEAL」「SUSTAINABLE」「GROWING」の4つのキーワードを軸に話を展開。BMSGのアーティストマネジメントの方針や育成プロジェクト、社会への取り組み、新プロジェクトなどを発表していった。**

これまでBMSGは「マネジメント/レーベル」と称し、2つの機能を持った会社であることを出してきましたが、今後は今まで以上に「マネジメント」機能を強調していきたい。これまではBMSGという言葉が指すものは、Aile The Shotaのレーベルかもしれないし、マネジメントかもしれないというふうに幅広かったのですが、今後はBMSG=マネジメントとなります。そのためにはレーベル機能にBMSG以外の名前を付けて、立たせる必要があると感じました。業務としては、これまでと大きく変わらないものの、「BullmooseRecords」の看板を出すことで、BMSG所属ではないアーティストの音楽業務も手伝いやすくなるとも考えています。

### 想像の5億倍面白い番組に

**時に「企業発表会」の動画のBullmooseパートでは、SKY-HIは海外にまでメッセージを届けるべく、英語でのプレゼンも行っていた。24年1月のインタビューでも、24年はソロアーティストがユナイトするプロジェクトを進めること、さらにその活動が国外に届く可能性を秘めたものになるかもしれないという予感を明かしていたが、実際にBullmooseを立ち上げる今はどう考えているのか。**

現時点ではまだ“新規事業の立ち上げ”に過ぎず、ピボット(事業転換)前提。状況によってBullmooseが何をするかも変わってくることが多々あると思います。まずは、1発目にリリースするBMSG POSSEで、しっかりかっこいいものを作って世に示したい。発表会でお話ししたようなアーティストの独立支援のためのオーダーメイド契約や海外展開も、BMSG POSSEの活動を示したうえで生まれていくものであるのかなと思っています。

**もう1つ、BMSGとちゃんみながタッグを組むガールズグループオーディション「No No Girls」の進捗も気になるところだ。発表会では24年中に最初のガールズグループがデビュー(その後、デビューは25年に変更)することを明かすとともに、「間違いなく時代を動かす、歴史を変えるグループが誕生すると思う」と大きな期待を語っていた。**
