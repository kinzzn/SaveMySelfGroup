# Constraints (限制条件)

为了确保加工后的稿件达到出版级质量，请在审读日译中稿件时，**必须严格拦截并修正以下“日式翻译腔”雷区**：

1. **彻底戒断日式被动句与使役句**：
* 日语极爱使用被动（～られる）和使役（～せる/させる）。
* **严禁**在中文里滥用“被”、“让”、“令”、“使得”。必须将其重构为中文的主动句或无主语句。
* *例：将“被大雨下了”改为“下起了大雨”；将“让我进行了思考”改为“引发了我的思考”。*


2. **拆解臃肿的“日式长定语”与倒装因果**：
* 日语习惯把极长的修饰成分放在名词前面，且喜欢用“因为……（～から/ので）”将因果倒置。
* 翻译成中文时，必须将多层嵌套的短语拆解为短句，或重新理顺“因果、转折”的逻辑顺序，严禁中文出现超过15个字以上的超长定语。


3. **消除“多余的助词和后缀惯性”**：
* 坚决清理以下带有明显日文痕迹的中文表述：
* 滥用“的”（如：“美丽的、高尚的、让人向往的学校”，应改为“美丽高尚且令人向往的学校”）。
* 机械死译“关于……”（关于～について）、“针对……”（～に対して）、“所谓……”（～というものは）。




4. **化解过度客套与委婉语（敬语残留）**：
* 日语为了礼貌，常用“似乎/好像/觉得/大概（～と思う/～らしい）”或“进行了……（～を行う）”。
* 翻译成中文的社科或商业著作时，这些虚化的语气词会削弱论证的坚定度。编辑必须删减这些无意义的委婉词，使中文表达更加坚定、直接。


5. **片假名外来语的精准回译**：
* 日语中的片假名外来语（如来自英语、德语）在翻译时最易出错。必须对照原文查证其源语言，并采用该专业领域的行业标准中文译名，不可听凭翻译根据音译瞎编。

# 四、专有名词的翻译原则

## 4.1 英文名称

1. 公司、厂牌、组合、艺名、节目名、歌曲名原则上保留英文。
2. 保留官方大小写、冒号、连字符、句号、撇号及特殊符号。
3. 首次出现时可根据读者理解需要添加中文说明，但不得每次重复。
4. 不将英文艺名强行意译。
5. `feat.`、`BMSG`、`CEO`、`MC`、`D.U.N.K.`等行业惯用缩写保留原文和标点。
6. 同一名称不得在不同章节分别译作中文或英文。

## 4.2 作品名与活动名

- 书籍、文章、节目、电影、专辑、单曲、舞台剧：使用中文书名号《》。
- 巡演、音乐节、公司项目及活动品牌：通常保留英文，不额外添加书名号。
- 作品名称内部已有引号、冒号、连字符时，保留原有格式。
- “D.U.N.K.”不得写成“DUNK”；“BE:FIRST”不得省略冒号。
- “BE:the ONE”中的冒号和大小写不得改动。
- “BE:1”与“2:BE”不得混淆。

## 4.3 人名

1. 艺名优先保留官方拼写。
2. 日本姓名采用官方通行中文译名；无法确认时不擅自创造汉字译名。
3. 人物昵称应保留亲密程度：
   - `コア`：只可译为“Core”。
   - `りょんりょん`：首次出现应说明为佐藤凉子的昵称。
4. 访谈中使用姓氏、名字或昵称时，必须保留原文的亲疏关系。
5. 不因中文表达习惯而擅自把所有人物改称全名。

# 五、文体与叙事结构规范

## 5.1 总体文风

本书中文应呈现以下综合特征：

- **出版报道体**：准确、清楚、结构严谨。
- **人物访谈体**：保留说话者的停顿、反问、转折与自我修正。
- **管理学表达**：概念明确，避免空泛鸡汤。
- **音乐行业语境**：熟悉现场、制作、发行、艺人管理等专业表达。
- **艺术家口吻**：保留热情、想象力、感性与偶尔的夸张。
- **第一人称真实性**：不得把口语润色成冷冰冰的书面报告。
- **第三人称客观性**：记者叙述应克制，不替人物下结论。

## 5.2 第三人称报道部分

### 基本特征

第三人称部分通常由记者撰写，具有以下特点：

- 事实密度高；
- 时间、地点、作品、成绩交代清楚；
- 适度评价舞台与组织发展；
- 常用“……的意义在于”“……可以说是……”等分析句；
- 语气客观，但不完全冷峻；
- 会通过现场观察表现人物状态。

### 中文处理规范

1. 句子可以适当拆分，避免日文长句堆叠。
2. 事实信息不得遗漏：
   - 日期；
   - 演出地点；
   - 公演数量；
   - 参与艺人；
   - 发行时间；
   - 榜单成绩；
   - 项目关系。
3. 日文中的“〜と言っても過言ではない”统一处理为：
   - “称其为……并不为过”
   - “可以说……并不夸张”
4. 日文中的“〜ように思えた”可译为：
   - “让人感到……”
   - “似乎……”
   - “给人留下了……的印象”
5. 避免将记者观察写成绝对判断。
6. “大きく動いた”根据语境译为“迎来重要进展”“发生重大变化”，不译为“动得很大”。
7. “快進撃”统一优先译为“强劲发展势头”“高歌猛进”，避免过度军事化。
8. “圧巻”可译为“震撼”“气势十足”“令人叹为观止”，根据上下文选择。
9. “堂々たる姿”统一优先译为“从容而自信的姿态”或“气场十足的表现”。

## 5.3 SKY-HI／日高光启的第一人称发言

### 人物基调

SKY-HI的语言同时具有以下层次：

1. **经营者的理性**
   - 重视结构、机制、可持续性、组织成长；
   - 会明确区分“梦想”“目标”“里程碑”“必达条件”；
   - 习惯从产业、公司与长期愿景的角度思考。

2. **艺术家的感性**
   - 重视音乐、身体性、情绪、氛围、直觉；
   - 常用“喜欢就是喜欢”“让人心动”“幸福”等表达；
   - 具有强烈的现场感和想象力。

3. **创业者的行动力**
   - 频繁使用“要做”“必须做”“不做就不会改变”等句式；
   - 对行业问题直言不讳；
   - 语气有时热烈、急切，带有自我驱动感。

4. **平等、亲近的沟通方式**
   - 不摆出高高在上的社长姿态；
   - 对艺人、员工、粉丝、合作伙伴多使用尊重和感谢；
   - 经常以“我也……”进行自我反省或自我定位。

5. **幽默与自嘲**
   - `妄信もあります（笑）`等表达应保留轻松感；
   - `奇特な人生ですね`可译为“真是段奇特的人生”；
   - 笑声、停顿、补充说明不宜全部删除。

### 中文语气规范

- 使用自然的现代中文口语，但避免网络化、低俗化。
- 可以使用“其实”“我觉得”“确实”“说到底”“当然”等口语连接词。
- 不把所有发言改成正式演讲稿。
- 不将“〜ですよね”机械翻译为“对吧”；根据语气可译为：
  - “确实如此。”
  - “我也是这么觉得的。”
  - “……不是吗？”
  - “说到底，……”
- 不将“〜じゃないですか”全部译为反问；可能是强调、确认或自我解释。
- `〜なんですよね`可译为：
  - “其实是……”
  - “……就是这么回事。”
  - “我当时确实……”
- `〜と思います`根据确定程度译为“我认为”“我觉得”“我想”。
- `〜かなと思っています`应保留谨慎感，可译为“我想……”“我倾向于认为……”。
- `本当に`不可每次都译为“真的”；可根据语气处理为“确实”“非常”“实在是”“说实话”。

## 5.4 记者提问部分

记者的提问具有以下特点：

- 礼貌、清晰、层层推进；
- 通常先介绍事实，再提出问题；
- 会引用受访者过去说过的话；
- 可能使用较长的铺垫；
- 不应译出咄咄逼人的质问感。

### 中文处理原则

- 正式采访中使用“您”。
- 提问应自然、准确，不刻意模仿日语敬语层级。
- `〜について改めて聞いた`统一优先译为：
  - “我们再次请他谈了谈……”
  - “这次，我们首先请他回顾……”
- `〜ということだろうか`可译为：
  - “这意味着什么？”
  - “应该如何理解？”
  - “究竟是出于怎样的考虑？”
- 采访者对SKY-HI的称呼统一为“SKY-HI先生”或“SKY-HI”，全书须择一。正文叙述中优先使用“SKY-HI”。

  - 外来语使用频率；
  - 情绪强度；
  - 对成员、制作人、粉丝的称呼；
  - 是否常用自嘲、反问、停顿与省略。

在未完成个体化分析前，成员发言统一采用：

- 自然、年轻但不幼稚；
- 口语化但不网络化；
- 有礼貌但不僵硬；
- 保留个人差异，不强行统一成SKY-HI的语气。

## 7.2 “梦想”与“目标”

| 概念 | 统一区分 |
|---|---|
| 夢 | 梦想，具有超越现实限制的愿景 |

| マイルストーン | 里程碑，为长期梦想服务的阶段性成果 |

| ビジョン | 愿景，关于未来整体方向的设想 |

# 十、翻译禁忌

## 10.1 不得过度文学化

不得将管理、采访、行业表达改写成散文式抒情文字。例如：

- `会社を動かす仕組み`  
  不译为“让公司焕发生命力的齿轮”  
  应译为“推动公司运转的机制”。

- `空気感がいい`  
  不译为“空气中流淌着明媚的光”  
  应译为“整体氛围很好”。

## 10.2 不得网络化

避免以下表达：

- 炸裂；
- 爆杀；
- 杀疯了；
- 天花板；
- 封神；
- 破防；
- 内卷；
- 油管；
- 男团／女团。

除非原文明确使用相同强度的网络或流行表达，否则采用出版体。

## 10.3 不得擅自拔高或削弱

- `変えたい`可译为“想改变”，不自动改成“颠覆”。
- `大きな夢`可译为“大梦想”，不自动改成“宏伟蓝图”。
- `楽しい`可译为“开心”“愉快”，不自动改成“狂欢”。
- `強い意志`可译为“坚定意志”，不自动改成“革命决心”。
- `救世主`应保留为“救世主”，但不替作者增加宗教或政治色彩。

## 10.4 不得消除矛盾与犹豫

SKY-HI的发言中常有：

- “我觉得……”
- “可能是……”
- “其实我也……”
- “说实话……”
- 自我修正；
- 先肯定、后保留；
- 一边兴奋、一边担忧。

这些并非赘词，而是人物思考过程的重要组成部分，不得为追求简洁而全部删去。

一个团队里，大家彼此顾虑到一定程度，就可能出现互相观望、谁也不先行动的情况。不过，对 MAZZEL 来说，所有人都按自己的想法展现自我，这个组合才一定会更有趣。话虽如此，即使大家都尽情展现自己，我也不太能想象 Takkun（TAKUTO 的昵称）大吵大闹的样子（笑）。但正因为有他可以依靠，其他人才会觉得“尽情去做也没关系！”我认为，大家需要这样的底气。

如今公司规模扩大了，旗下艺人也增加了，不像 BE:FIRST 刚出道时那样，无论是哪位艺人的活动，我都越来越难做到每次亲临现场。你看，矫正牙齿时，如果连续好几天不戴牙套，牙齿不是很快就会恢复原样吗？道理是一样的，所以我希望能有人在现场持续贯彻我的想法。从这个意义上说，Takkun 或许就是保持器，也就是牙齿矫正后用来维持效果的装置。

他不是那种情绪每天起起伏伏的人。只要跟他说“我们上次是这么说的吧”，他就能立刻想起当时的状态，并进入其中。我觉得，这就是 MAZZEL 的现场所需要的角色。Takkun 本人也有很多俏皮的一面，但也有超出实际年龄的成熟——他现在 25 岁——而且意志坚定。我也觉得，如果有机会让他主动展现这些特质，对他本人也是一件好事。

我曾经想过，如果在《MISSION》这类展现 MAZZEL 态度的歌曲之前，由 Takkun 以队长身份说一段 MC，应该会呈现出不一样的魅力。虽然第一次巡演实际把这段 MC 放在了《MISSION》之后，但能看到 Takkun 新的一面，还是很好的。他脑子灵活，感觉也敏锐，所以我想，到了明年，大家或许会看到一个令人惊喜的 Takkun。

### 今后要进一步突出“独特性”

本次巡演将在 Pia Arena MM 和大阪城音乐厅各追加两场演出，共计四场。首次巡演的门票确实竞争激烈，但对出道才一年的组合来说，四场体育馆演出仍是相当大的规模。另一方面，有时也会让人觉得，他们“还没有被大众发现”。

应该有很多人没能买到票吧。相关数字高到了普通组合出道第一年几乎不可能达到的程度。事实上，目前 BMSG 旗下粉丝俱乐部会员人数增长率最高的，就是 MAZZEL。我觉得，现在的他们确实有一种魅力，不管在哪里，只要看过他们一次，就会想支持他们。这大概也是粉丝不断增加的原因。

先从能够看清观众席上一个个具体的人的规模起步，再逐步扩大，这和 BE:FIRST 当时的思路一样。不过，今后通过选秀企划 No No Girls 出道的女子组合，情况会有所不同；至于已经有舞台经验的第三个组合，我想又得换一个角度考虑。只是，第一次巡演究竟该做多少包装、保留多少未经修饰的本色，这个平衡很难把握。推进过程中，确实也有让我觉得必须谨慎拿捏的地方。

至于有人说他们“还没被发现”，其实我觉得，太在意这个也没什么用。真要这么说，任何组合都一样，我至今也会对 BE:FIRST 有这样的想法。只要还在做艺人，这就是永恒的课题，也是需要持续努力的目标。即使不断登上音乐节目，能触及的人群也终究有限，所以只能一次次抓住得到的登场机会。比起这些，首先更重要的是，他们现在已经有了这样的势头和成绩，粉丝也确实在不断增加，我们应该为这个现状感到高兴和感激。

不过，对于 MAZZEL，我确实想把他们的独特性再提升一个层次，更鲜明地展现出来。下一张单曲里，我已经有一些想做的事了。

对他们来说，我觉得，当人们再也找不到那种特殊、与众不同之处时，才是真正的危机。不过，我实在无法想象那一天会到来。
