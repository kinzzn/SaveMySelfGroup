# Constraints (限制条件)

为了确保加工后的稿件达到出版级质量，请在审读日译中稿件时，**必须严格拦截并修正以下“日式翻译腔”雷区**：

1. **彻底戒断日式被动句与使役句**：
* 日语极爱使用被动（～られる）和使役（～せる/させる）。
* **严禁**在中文里滥用“被”、“让”、“令”、“使得”。必须将其重构为中文的主动句或无主语句。
* *例：将“被大雨下了”改为“下起了大雨”；将“让我进行了思考”改为“引发了我的思考”。*


2. **拆解臃肿的“日式长定语”与倒装因果**：
* 日语习惯把极长的修饰成分放在名词前面，且喜欢用“因为……（～から/ので）”将因果倒置。
* 翻译成中文时，必须将多层嵌套的短语拆解为短句，或重新理顺“因果、转折”的逻辑顺序，严禁中文出现超过15个字以上的超长定语。


3. **消除“多余的助词和后缀惯性”**：
* 坚决清理以下带有明显日文痕迹的中文表述：
* 滥用“的”（如：“美丽的、高尚的、让人向往的学校”，应改为“美丽高尚且令人向往的学校”）。
* 机械死译“关于……”（关于～について）、“针对……”（～に対して）、“所谓……”（～というものは）。




4. **化解过度客套与委婉语（敬语残留）**：
* 日语为了礼貌，常用“似乎/好像/觉得/大概（～と思う/～らしい）”或“进行了……（～を行う）”。
* 翻译成中文的社科或商业著作时，这些虚化的语气词会削弱论证的坚定度。编辑必须删减这些无意义的委婉词，使中文表达更加坚定、直接。


5. **片假名外来语的精准回译**：
* 日语中的片假名外来语（如来自英语、德语）在翻译时最易出错。必须对照原文查证其源语言，并采用该专业领域的行业标准中文译名，不可听凭翻译根据音译瞎编。

# 四、专有名词的翻译原则

## 4.1 英文名称

1. 公司、厂牌、组合、艺名、节目名、歌曲名原则上保留英文。
2. 保留官方大小写、冒号、连字符、句号、撇号及特殊符号。
3. 首次出现时可根据读者理解需要添加中文说明，但不得每次重复。
4. 不将英文艺名强行意译。
5. `feat.`、`BMSG`、`CEO`、`MC`、`D.U.N.K.`等行业惯用缩写保留原文和标点。
6. 同一名称不得在不同章节分别译作中文或英文。

## 4.2 作品名与活动名

- 书籍、文章、节目、电影、专辑、单曲、舞台剧：使用中文书名号《》。
- 巡演、音乐节、公司项目及活动品牌：通常保留英文，不额外添加书名号。
- 作品名称内部已有引号、冒号、连字符时，保留原有格式。
- “D.U.N.K.”不得写成“DUNK”；“BE:FIRST”不得省略冒号。
- “BE:the ONE”中的冒号和大小写不得改动。
- “BE:1”与“2:BE”不得混淆。

## 4.3 人名

1. 艺名优先保留官方拼写。
2. 日本姓名采用官方通行中文译名；无法确认时不擅自创造汉字译名。
3. 人物昵称应保留亲密程度：
   - `コア`：只可译为“Core”。
   - `りょんりょん`：首次出现应说明为佐藤凉子的昵称。
4. 访谈中使用姓氏、名字或昵称时，必须保留原文的亲疏关系。
5. 不因中文表达习惯而擅自把所有人物改称全名。

# 五、文体与叙事结构规范

## 5.1 总体文风

本书中文应呈现以下综合特征：

- **出版报道体**：准确、清楚、结构严谨。
- **人物访谈体**：保留说话者的停顿、反问、转折与自我修正。
- **管理学表达**：概念明确，避免空泛鸡汤。
- **音乐行业语境**：熟悉现场、制作、发行、艺人管理等专业表达。
- **艺术家口吻**：保留热情、想象力、感性与偶尔的夸张。
- **第一人称真实性**：不得把口语润色成冷冰冰的书面报告。
- **第三人称客观性**：记者叙述应克制，不替人物下结论。

## 5.2 第三人称报道部分

### 基本特征

第三人称部分通常由记者撰写，具有以下特点：

- 事实密度高；
- 时间、地点、作品、成绩交代清楚；
- 适度评价舞台与组织发展；
- 常用“……的意义在于”“……可以说是……”等分析句；
- 语气客观，但不完全冷峻；
- 会通过现场观察表现人物状态。

### 中文处理规范

1. 句子可以适当拆分，避免日文长句堆叠。
2. 事实信息不得遗漏：
   - 日期；
   - 演出地点；
   - 公演数量；
   - 参与艺人；
   - 发行时间；
   - 榜单成绩；
   - 项目关系。
3. 日文中的“〜と言っても過言ではない”统一处理为：
   - “称其为……并不为过”
   - “可以说……并不夸张”
4. 日文中的“〜ように思えた”可译为：
   - “让人感到……”
   - “似乎……”
   - “给人留下了……的印象”
5. 避免将记者观察写成绝对判断。
6. “大きく動いた”根据语境译为“迎来重要进展”“发生重大变化”，不译为“动得很大”。
7. “快進撃”统一优先译为“强劲发展势头”“高歌猛进”，避免过度军事化。
8. “圧巻”可译为“震撼”“气势十足”“令人叹为观止”，根据上下文选择。
9. “堂々たる姿”统一优先译为“从容而自信的姿态”或“气场十足的表现”。

## 5.3 SKY-HI／日高光启的第一人称发言

### 人物基调

SKY-HI的语言同时具有以下层次：

1. **经营者的理性**
   - 重视结构、机制、可持续性、组织成长；
   - 会明确区分“梦想”“目标”“里程碑”“必达条件”；
   - 习惯从产业、公司与长期愿景的角度思考。

2. **艺术家的感性**
   - 重视音乐、身体性、情绪、氛围、直觉；
   - 常用“喜欢就是喜欢”“让人心动”“幸福”等表达；
   - 具有强烈的现场感和想象力。

3. **创业者的行动力**
   - 频繁使用“要做”“必须做”“不做就不会改变”等句式；
   - 对行业问题直言不讳；
   - 语气有时热烈、急切，带有自我驱动感。

4. **平等、亲近的沟通方式**
   - 不摆出高高在上的社长姿态；
   - 对艺人、员工、粉丝、合作伙伴多使用尊重和感谢；
   - 经常以“我也……”进行自我反省或自我定位。

5. **幽默与自嘲**
   - `妄信もあります（笑）`等表达应保留轻松感；
   - `奇特な人生ですね`可译为“真是段奇特的人生”；
   - 笑声、停顿、补充说明不宜全部删除。

### 中文语气规范

- 使用自然的现代中文口语，但避免网络化、低俗化。
- 可以使用“其实”“我觉得”“确实”“说到底”“当然”等口语连接词。
- 不把所有发言改成正式演讲稿。
- 不将“〜ですよね”机械翻译为“对吧”；根据语气可译为：
  - “确实如此。”
  - “我也是这么觉得的。”
  - “……不是吗？”
  - “说到底，……”
- 不将“〜じゃないですか”全部译为反问；可能是强调、确认或自我解释。
- `〜なんですよね`可译为：
  - “其实是……”
  - “……就是这么回事。”
  - “我当时确实……”
- `〜と思います`根据确定程度译为“我认为”“我觉得”“我想”。
- `〜かなと思っています`应保留谨慎感，可译为“我想……”“我倾向于认为……”。
- `本当に`不可每次都译为“真的”；可根据语气处理为“确实”“非常”“实在是”“说实话”。

## 5.4 记者提问部分

记者的提问具有以下特点：

- 礼貌、清晰、层层推进；
- 通常先介绍事实，再提出问题；
- 会引用受访者过去说过的话；
- 可能使用较长的铺垫；
- 不应译出咄咄逼人的质问感。

### 中文处理原则

- 正式采访中使用“您”。
- 提问应自然、准确，不刻意模仿日语敬语层级。
- `〜について改めて聞いた`统一优先译为：
  - “我们再次请他谈了谈……”
  - “这次，我们首先请他回顾……”
- `〜ということだろうか`可译为：
  - “这意味着什么？”
  - “应该如何理解？”
  - “究竟是出于怎样的考虑？”
- 采访者对SKY-HI的称呼统一为“SKY-HI先生”或“SKY-HI”，全书须择一。正文叙述中优先使用“SKY-HI”。

  - 外来语使用频率；
  - 情绪强度；
  - 对成员、制作人、粉丝的称呼；
  - 是否常用自嘲、反问、停顿与省略。

在未完成个体化分析前，成员发言统一采用：

- 自然、年轻但不幼稚；
- 口语化但不网络化；
- 有礼貌但不僵硬；
- 保留个人差异，不强行统一成SKY-HI的语气。

## 7.2 “梦想”与“目标”

| 概念 | 统一区分 |
|---|---|
| 夢 | 梦想，具有超越现实限制的愿景 |

| マイルストーン | 里程碑，为长期梦想服务的阶段性成果 |

| ビジョン | 愿景，关于未来整体方向的设想 |

# 十、翻译禁忌

## 10.1 不得过度文学化

不得将管理、采访、行业表达改写成散文式抒情文字。例如：

- `会社を動かす仕組み`  
  不译为“让公司焕发生命力的齿轮”  
  应译为“推动公司运转的机制”。

- `空気感がいい`  
  不译为“空气中流淌着明媚的光”  
  应译为“整体氛围很好”。

## 10.2 不得网络化

避免以下表达：

- 炸裂；
- 爆杀；
- 杀疯了；
- 天花板；
- 封神；
- 破防；
- 内卷；
- 油管；
- 男团／女团。

除非原文明确使用相同强度的网络或流行表达，否则采用出版体。

## 10.3 不得擅自拔高或削弱

- `変えたい`可译为“想改变”，不自动改成“颠覆”。
- `大きな夢`可译为“大梦想”，不自动改成“宏伟蓝图”。
- `楽しい`可译为“开心”“愉快”，不自动改成“狂欢”。
- `強い意志`可译为“坚定意志”，不自动改成“革命决心”。
- `救世主`应保留为“救世主”，但不替作者增加宗教或政治色彩。

## 10.4 不得消除矛盾与犹豫

SKY-HI的发言中常有：

- “我觉得……”
- “可能是……”
- “其实我也……”
- “说实话……”
- 自我修正；
- 先肯定、后保留；
- 一边兴奋、一边担忧。

这些并非赘词，而是人物思考过程的重要组成部分，不得为追求简洁而全部删去。

## 希望通过 BE:FIRST 第二张专辑向社会展现的精神
#领导力 #成长 #音乐制作 #BEFIRST

### “我必须时刻意识到，自己有责任为他们创造成长机会”

**BE:FIRST 的第二张专辑《2:BE》于 2024年8月28日发行。专辑发行前先行上线的主打歌《Blissful》，在 8月21日公布的 Billboard JAPAN 综合歌曲榜 JAPAN Hot 100 中登顶，并在各类音乐榜单上斩获 185 项第一。**

**距离首张专辑《BE:1》发行，恰好过去了两年。这期间，BE:FIRST 首次在东京、大阪举行巨蛋演出，大获成功，如今已稳居日本代表性男子组合之列。与此同时，从《Boom Boom Back》到《Mainstream》，再到《Masterplan》，他们作为艺人的自我意识迅速成长。因此，大家格外期待他们会在这张堪称新篇章开端的第二张专辑中展现怎样的面貌。SKY-HI 又是如何构想这张专辑的理念与定位的呢？**

从出道之初，我并不是没有考虑过之后几张专辑的方向。不过，制作首张专辑《BE:1》时，我心里有一个总体规划：用这张专辑收录的歌曲登上巨蛋舞台。因此，早在出道曲《Gifted.》发行之前，我们就已经朝着明确的目标和设想中的整体音响风格迈进了。我当时想，这张专辑必须把“从一无所有的零起点出发，最终站上东京巨蛋舞台”的过程呈现为一个故事，让参与其中的不只是我们和粉丝，还有整个社会。回过头来看，那应该是一个围绕这条主线，思考当下应该歌唱什么、传达什么，再逐渐聚焦的过程。

第二张及之后的专辑也延续了这个方向。不过，要创作出符合他们当下状态的作品，唱出那个阶段应该歌唱、应该传达以及想做的事情，就必须在制作过程中认真面对他们的变化。所以，我们始终提醒自己保持灵活的思路来推进制作。

说到底，与个人艺人相比，他们有 7 个人。哪怕只是稍微换个角度，按人数来算，至少也应该有 7 倍的表达空间。而且，只要社会还在不断变化，他们就始终有应该歌唱的内容。尤其在如今这个很难称得上和平的世界里，我觉得，应该唱的、能够唱的、大家需要的音乐，以及单纯觉得“做出来一定很有意思”的音乐，都还有很多。

在这样的背景下，第二张专辑《2:BE》有一个重要主题：当整个社会盛行拖别人后腿、挤掉别人的风气时，我们希望把 BE:FIRST 自然拥有的那种彼此“赞美”“称赞”的精神，清楚地展现给社会。娱乐圈经常有人说：“组合只要能顺利开展工作，成员之间不一定非要关系好。”但我自己一直很不认同这句话。既然特意组建一个组合，就应该有“正因为是这些成员、这个组合，所以才想一起做下去”的必然理由，组合内部也应该有这样的氛围。

稍微岔开一下话题，我一直觉得，“每逢值得庆祝的事，都一定要好好庆祝”。拿了什么第一，或者达成了某个目标，就马上庆祝。因为这样更开心，也能带来自我肯定和对他人的肯定。BE:FIRST 举行巨蛋演出之后，比起说“没有没有，也没什么了不起的，我们还差得远”，我更重视营造一种彼此称赞的氛围，让大家能够说：“一路走来，我们真的很努力，做到了！”“我们真了不起。”总之，就是要传达自我关爱的精神，展现这种在自我肯定之上再加上肯定他人、我认为世上最可贵的价值观。这就是以《Blissful》为主打歌的《2:BE》的存在意义。

### 全体成员参与歌曲制作

**这张专辑以第一首歌《Slogan》开篇，高声宣告了 BE:FIRST 一路走来的历程，以及如今他们应有的模样。不过，初听时让我感到意外的，是第 13 首《BE:0-interlude-》。那段出乎意料的发展，加上饱含情感的声音，让我心头一下子涌起一股热意。**

为了突出歌曲想传达的信息，在专辑中插入间奏曲（interlude），应该是很常见的做法。不过，一般来说，组合的专辑比较少这样做。我很早就觉得，如果因为是组合就做不了，未免有些可惜。甚至有时会让我觉得，专辑的曲目顺序，以及一首歌为什么由这个人来唱，这些意义似乎没有得到足够重视。《BE:0-interlude-》之后的《Glorious》，本来就是从 THE FIRST 一路走到今天的这 7 个人赞美自己的歌……其实，我觉得光听歌就能明白这一点。但同时又觉得，我们一起经历的这段时光，值得再表达得更明确、更突出一些，我想把它好好呈现出来，所以用了 THE FIRST 时期的录音。

大致就是一边制作《Glorious》，一边在心里构思这首间奏曲。

**这次，MANATO 和 LEO 参与了主打歌《Blissful》的制作，3 首小分队歌曲的演唱成员也分别出现在制作名单中。让全体成员参与制作，是出于怎样的考虑呢？**

谁也不知道，什么会成为一个人成长的契机，对吧？像他们这样从事音乐工作的人，会想亲自创作音乐，或者希望自己具备创作能力，我觉得是再自然不过的事。当然，我们也有专业上的要求，不能因为是自己的成员，就迁就他们，不论什么作品都拿出来发行。不过，我觉得这次也确实做出了水准很高的歌曲。

我必须时刻意识到，自己有责任为他们创造成长机会。经过这样的体验，或许会促使我为某位成员提供进一步发展其独特艺术性的机会。而且，受到激发的也不只是创作能力。参与歌曲制作的过程，可能会让他们更加喜欢音乐；更喜欢音乐，耳力也会随之提升，进而唱得更好。我也觉得，了解制作过程之后，彼此就能围绕歌曲更深入地交换意见。

以前和 BE:FIRST 聊起“我们想做这样的歌”时，他们的回应就不只是“很酷”之类的话，而是会说：“上次做的是 2000 年前后那种风格，下次是不是可以试试 2010 年左右的感觉，配上这样的律动？”他们有一个很好的地方，就是只要听了参考曲，就能理解我们背后的意图。我期待通过不断积累这样的制作经历，让他们对音乐形成更系统、更深入的理解。

所以，让成员参与制作，确实只有好处。唯一辛苦的地方，就是费时间。如果我一个人来做，大多数制作工作两三个小时就能完成，但一起做，至少需要两倍的时间，有时还得各自带回去继续做，所以要说辛苦，也确实辛苦。毕竟，我的两三个小时可是很贵的（笑）。不过，考虑到他们的未来，这些都是无可替代的时间和经历。而且，通过这些经历，他们今后想做什么、应该做什么，也会越来越具体。到那时，该做怎样的歌曲、与哪位创作者以怎样的方式合作，自然也会逐渐清晰起来。音乐人之间的沟通越准确，作品的完成度也会越高。

至少要让音乐行业的各位都觉得：“在 BMSG，即便具体到组合中的每一位成员，每个人的音乐水准和音乐意识都有保障。”这是我的使命。他们只管按自己的意愿，做自己喜欢的事。而我要做的，就是为他们开路、铺路，让这样的选择能够行得通。因为处在这个位置，我也多少能看见一些他们的未来。一想到几年后的他们，就觉得未来真是充满可能。很期待（笑）。
