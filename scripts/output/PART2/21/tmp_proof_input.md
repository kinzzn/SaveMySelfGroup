# 四、专有名词的翻译原则

## 4.1 英文名称

1. 公司、厂牌、组合、艺名、节目名、歌曲名原则上保留英文。
2. 保留官方大小写、冒号、连字符、句号、撇号及特殊符号。
3. 首次出现时可根据读者理解需要添加中文说明，但不得每次重复。
4. 不将英文艺名强行意译。
5. `feat.`、`BMSG`、`CEO`、`MC`、`D.U.N.K.`等行业惯用缩写保留原文和标点。
6. 同一名称不得在不同章节分别译作中文或英文。

## 4.2 作品名与活动名

- 书籍、文章、节目、电影、专辑、单曲、舞台剧：使用中文书名号《》。
- 巡演、音乐节、公司项目及活动品牌：通常保留英文，不额外添加书名号。
- 作品名称内部已有引号、冒号、连字符时，保留原有格式。
- “D.U.N.K.”不得写成“DUNK”；“BE:FIRST”不得省略冒号。
- “BE:the ONE”中的冒号和大小写不得改动。
- “BE:1”与“2:BE”不得混淆。

## 4.3 人名

1. 艺名优先保留官方拼写。
2. 日本姓名采用官方通行中文译名；无法确认时不擅自创造汉字译名。
3. 人物昵称应保留亲密程度：
   - `コア`：只可译为“Core”。
   - `りょんりょん`：首次出现应说明为佐藤凉子的昵称。
4. 访谈中使用姓氏、名字或昵称时，必须保留原文的亲疏关系。
5. 不因中文表达习惯而擅自把所有人物改称全名。

# 五、文体与叙事结构规范

## 5.1 总体文风

本书中文应呈现以下综合特征：

- **出版报道体**：准确、清楚、结构严谨。
- **人物访谈体**：保留说话者的停顿、反问、转折与自我修正。
- **管理学表达**：概念明确，避免空泛鸡汤。
- **音乐行业语境**：熟悉现场、制作、发行、艺人管理等专业表达。
- **艺术家口吻**：保留热情、想象力、感性与偶尔的夸张。
- **第一人称真实性**：不得把口语润色成冷冰冰的书面报告。
- **第三人称客观性**：记者叙述应克制，不替人物下结论。

## 5.2 第三人称报道部分

### 基本特征

第三人称部分通常由记者撰写，具有以下特点：

- 事实密度高；
- 时间、地点、作品、成绩交代清楚；
- 适度评价舞台与组织发展；
- 常用“……的意义在于”“……可以说是……”等分析句；
- 语气客观，但不完全冷峻；
- 会通过现场观察表现人物状态。

### 中文处理规范

1. 句子可以适当拆分，避免日文长句堆叠。
2. 事实信息不得遗漏：
   - 日期；
   - 演出地点；
   - 公演数量；
   - 参与艺人；
   - 发行时间；
   - 榜单成绩；
   - 项目关系。
3. 日文中的“〜と言っても過言ではない”统一处理为：
   - “称其为……并不为过”
   - “可以说……并不夸张”
4. 日文中的“〜ように思えた”可译为：
   - “让人感到……”
   - “似乎……”
   - “给人留下了……的印象”
5. 避免将记者观察写成绝对判断。
6. “大きく動いた”根据语境译为“迎来重要进展”“发生重大变化”，不译为“动得很大”。
7. “快進撃”统一优先译为“强劲发展势头”“高歌猛进”，避免过度军事化。
8. “圧巻”可译为“震撼”“气势十足”“令人叹为观止”，根据上下文选择。
9. “堂々たる姿”统一优先译为“从容而自信的姿态”或“气场十足的表现”。

## 5.3 SKY-HI／日高光启的第一人称发言

### 人物基调

SKY-HI的语言同时具有以下层次：

1. **经营者的理性**

   - 重视音乐、身体性、情绪、氛围、直觉；
   - 常用“喜欢就是喜欢”“让人心动”“幸福”等表达；
   - 具有强烈的现场感和想象力。

3. **创业者的行动力**
   - 频繁使用“要做”“必须做”“不做就不会改变”等句式；
   - 对行业问题直言不讳；
   - 语气有时热烈、急切，带有自我驱动感。

4. **平等、亲近的沟通方式**
   - 不摆出高高在上的社长姿态；
   - 对艺人、员工、粉丝、合作伙伴多使用尊重和感谢；
   - 经常以“我也……”进行自我反省或自我定位。

5. **幽默与自嘲**
   - `妄信もあります（笑）`等表达应保留轻松感；
   - `奇特な人生ですね`可译为“真是段奇特的人生”；
   - 笑声、停顿、补充说明不宜全部删除。

### 中文语气规范

- 使用自然的现代中文口语，但避免网络化、低俗化。
- 可以使用“其实”“我觉得”“确实”“说到底”“当然”等口语连接词。
- 不把所有发言改成正式演讲稿。
- 不将“〜ですよね”机械翻译为“对吧”；根据语气可译为：
  - “确实如此。”
  - “我也是这么觉得的。”
  - “……不是吗？”
  - “说到底，……”
- 不将“〜じゃないですか”全部译为反问；可能是强调、确认或自我解释。
- `〜なんですよね`可译为：
  - “其实是……”
  - “……就是这么回事。”
  - “我当时确实……”
- `〜と思います`根据确定程度译为“我认为”“我觉得”“我想”。
- `〜かなと思っています`应保留谨慎感，可译为“我想……”“我倾向于认为……”。
- `本当に`不可每次都译为“真的”；可根据语气处理为“确实”“非常”“实在是”“说实话”。

- 提问应自然、准确，不刻意模仿日语敬语层级。

# 七、关键词与核心理念的统一表达

## 7.1 “做自己”理念

以下表达必须保持语义关联：

| 原文 | 统一译法 |
|---|---|
| Be MySelf Group | Be MySelf Group |
| ありのままの自分で生きる | 做真实的自己／以本来的自己生活 |
| 自分らしく | 按自己的方式／做自己 |
| 自分自身のまま | 保持真实的自我 |
| 自分の居場所 | 自己的归属之处 |
| 自分の魂の声を聞く | 聆听自己灵魂的声音 |
| 自分の好きに正直に | 忠于自己的喜好 |
| 「好き＝好き」 | “喜欢就是喜欢” |
| 身体的・本能的に「好き＝好き」でいられる | 在身体和本能层面都能坦然地“喜欢就是喜欢” |

不得把“自分らしさ”在不同章节随意译成“个性”“自我”“本真”“真实自我”，除非上下文确实要求区分。

## 7.2 “梦想”与“目标”

| 概念 | 统一区分 |
|---|---|
| 夢 | 梦想，具有超越现实限制的愿景 |
| 目標 | 目标，具有现实可执行性 |
| マイルストーン | 里程碑，为长期梦想服务的阶段性成果 |
| 必達条件 | 必须完成、不可退让的条件 |
| ビジョン | 愿景，关于未来整体方向的设想 |

推荐译法：

> “目标”能够放大实现可能之事的可能性；而“梦想”，则可能让不可能之事变为可能。

不得将“梦想”和“目标”混译。

| 原文 | 推荐译法 |

| いい空気感 | 良好的氛围／舒服的氛围 |

“空気感”不是单纯的“气氛”，还包含人与人之间的关系、身体感受、现场温度与心理安全感。必要时可根据上下文译为“氛围”“气场”“现场感”，但同一段中应避免反复变换。

# 十、翻译禁忌

## 10.1 不得过度文学化

不得将管理、采访、行业表达改写成散文式抒情文字。例如：

- `会社を動かす仕組み`  
  不译为“让公司焕发生命力的齿轮”  
  应译为“推动公司运转的机制”。

- `空気感がいい`  
  不译为“空气中流淌着明媚的光”  
  应译为“整体氛围很好”。

## 10.2 不得网络化

避免以下表达：

- 炸裂；
- 爆杀；
- 杀疯了；
- 天花板；
- 封神；
- 破防；
- 内卷；
- 油管；
- 男团／女团。

除非原文明确使用相同强度的网络或流行表达，否则采用出版体。

## 10.3 不得擅自拔高或削弱

- `変えたい`可译为“想改变”，不自动改成“颠覆”。
- `大きな夢`可译为“大梦想”，不自动改成“宏伟蓝图”。
- `楽しい`可译为“开心”“愉快”，不自动改成“狂欢”。
- `強い意志`可译为“坚定意志”，不自动改成“革命决心”。
- `救世主`应保留为“救世主”，但不替作者增加宗教或政治色彩。

## 10.4 不得消除矛盾与犹豫

SKY-HI的发言中常有：

- “我觉得……”
- “可能是……”
- “其实我也……”
- “说实话……”
- 自我修正；
- 先肯定、后保留；
- 一边兴奋、一边担忧。

这些并非赘词，而是人物思考过程的重要组成部分，不得为追求简洁而全部删去。

**2023年7月20日に登壇した「日経クロストレンドFORUM 2023」のテーマは「続・音楽ビジネス革命一『嘘がつけない時代』のファンとの関係」。22年の同講演で、「今の時代のヒットに必要不可欠な要件は『嘘がないこと』」と語ったSKY-HIに、ファンとの向き合い方について聞いた。(聞き手は吾妻拓 日経クロストレンド編集委員)**

———— 5月に東京・代々木第一体育館で「SKY-HI ARENA TOUR 2023 -BOSSDOM」を拝見しました。エンタテインメントとして隙のないステージ構成と演出、そして迫力に感動して帰途に就いたのですが、MCでの最も印象的な言葉の1つが、「BMSGは、あなたたちと一緒に時代を変える」という宣言でした。その強烈なメッセージに鳥肌が立つ感じすらしましたが、なかでも「あなたたちと一緒に」という部分はSKY-HIさんの考え方を象徴しているんじゃないかと感じました。アーティストとしてのSKY-HI、社長としてのSKY-HI、それぞれにとってファンというのはどんな存在になるんですか？

よくこういった話題に対して、特に経済系のメディアさんですと、いわゆる「ファンダムの力」をメインにされると思います。ビジネス視点としては間違ってないと思うんですけど、正直、ちょっとミスリードな部分もあるなとは思ったりするところもありますね。というのも、要は「ファンが能動的に数字を作れる時代」である。これは確かだと思うのですが、そのためにするべきことって、例えば「需要」や「マーケット」といったものが存在する場所を狙って石を投げていく作業ではないと思うんです。アーティストが「その人でないといけない理由」おそらく人の数だけあると思いますが、音楽が良い、歌がうまい、ダンスがうまいだけでは理由にはならないですし、逆に人間的な魅力だけでも理由にならない。アーティストおよび社長として所属アーティストに求めるのは、その両方ですね。両方ないと絶対にダメだと思います。

アーティスト、アイドル、芸能人を好きになるときの「その人でないといけない」と思うきっかけもまた、人の数ほどあると思いますが、僕らからすると、それに対して甘えた作業をすればするほどカルチャーとかシーンとしての力は弱まっていき、結果として、荒廃、衰退、殺伐といった空気感がついて回ってしまうと思います。特にこれからの時代は、アーティスト、アイドル側がファンを啓蒙する側面が絶対になくてはいけないと思います。「実際に数字を動かす存在としてのファン」と「この人でないといけないと思わせる力を持つアーティスト」という両者の相互作用が不可欠です。アーティストがやっていることは当然ファンの方にはできないことだと思いますが、同様にファンの方がやってることもアーティストには絶対にできないことだと思うので、両者の関係性は甘えずに作っていくべきものだと考えています。

———— ファンを啓蒙していく場として象徴的なのがライブですよね。SKY-HIさんは以前、「アーティストはファンとライブのステージで会うのが1番正しい」とおっしゃっていましたが、BMSG所属のアーティストの方々のMCは、ファンの方々に対して1人の人間として一生懸命メッセージを伝えようとされている印象があります。

まさしくそれは、両者の「健康的な関係」として絶対に大事なことのような気がしています。「ファンあってのアイドル」みたいな言葉ってありますが、あれはどこにとってもいいことがないなと思うんですよ。ただ単にファンの方に喜んでもらうことのみがゴールになってしまうと、アーティストの自意識と乖離してしまうのが1つ。アートやパフォーマンスって本来全ては自意識から発露するものだと思うんです。「こういった表現をしたい」「音楽をこう表現したい」「こういう曲を作って、こういう存在としてステージに立ちたい」という気持ちと乖離してしまう。ステージ上でも、ものすごく丁寧なパフォーマンスをするよりも、ファンの方々と目を合わせたり手を振ったりとかしたほうが即時的には盛り上がっているように見えますし、された方は当然うれしいですから。それがすご大切で同時に破壊力があることだと分かっているからこそ、そこにお互い依存することで歪な関係が生まれてしまうと、音楽に向かう気持ちが双方共に薄れてしまう。ファンの方がライブに行くモチベーションが手を振ってもらうことになってしまい、アーティストの最大のミッションが手を振ることになってしまった場合、薄くなっていく、揺らいでいくものがあることは想像いただけると思います。アーティストもそうした手を振るだけで盛り上がるみたいなものを成功体験として体に刻み込んでしまうと、心からのコミュニケーションを1対1で取るのではなく、客席にいる方々に対してざっくりとした「ファンのみんな」みたいな認識になってしまうんですよね。「ファンのみんな」っていうワードってすごく乱暴というか、人によってアーティストにかける思いもお金も年数もバラバラだと思いますし、アーティストがそれぞれに思いを馳せるのは最低限集まっていただいた方に対する礼儀のように思います。その気持ちがあると、個々人として向き合ったうえで感謝できるのではというふうに思っています。それは絶対に必要なことです。何か礼節みたいなところに近い気がしますが、本当にそれに尽きるかな。

———— なるほど。ファンの気持ちを想像し、真心を込めてメッセージを放つという。そのときに、共感してもらえるポイントみたいものは、どう探ってるんでしょうか。

これは前回の登壇時(22年)にお話ししたこととつながるのですが、とにかく「嘘をつかないコミュニケーション」をする場合、自分のアウトプットとファンが刺さるポイントが、コアファンであればあるほど合致する点が多いと思います。あとは、普段から強く思っていること、信じていることをライブの高揚感に自分が身を任せて、そのままより強くストレートに発すると、結果として共感を生むことになると思います。言葉や心の服を脱ぐことが、アーティストがする責務です。

今はニーズの多様化も広がっている時代で、アーティストにとっては素晴らしいことだと思うんですけど、そのなかで「嘘をつかなくていい」というのは本当にあると思うんですよね。例えば、アイドルだからこうしないといけない、アイドルだからおそろいの衣装で常に笑顔で、辛いところは見せちゃいけないみたいな価値観は、おそらく平成の末期に全部忘却の彼方に置いていったように思うんです。今の時代は、自分がどういう存在であるかということを、普段から嘘をつかずに発することができていると、自ずと共感が生まれるんじゃないかなと思います。例えば自分がエリンギなのに牛肉だと偽ることをステージで求められて時代は本当に長かったと思います。でも、今は「エリンギはエリンギでいい」という時代なんです。自分を偽って「振り」をするのはかなり大変です。大変な思いをして牛肉の振りをしても、みんなちょっと気づくんですよね。「あいつ、牛肉じゃなくてソイミートじゃない？」って。そうなると個人の数字も伸びづらいし、うまく偽装したつもりでもバレる時代だと思いますよ。

———— 嘘をつかないことで、どんどん共感してもらっていった先にあるのが、BMSGが運営するオンラインサロン「B-Town」ですね。これは本当にコアなファン、強く共感してくれたファンが集う場所の1つだと思いますが、月額5000円の「Architect」コースに1万人超の会員がいらっしゃる。以前は「オンラインサロン的なファンコミュニティ」だったのが、今は「オンラインサロン」と呼ばれていますが、この違いはどこにあるんですか？

大きく2つあって、起業した頃、オンラインサロンっていう存在への風向きが、ちょっとネオリベラルなものになりすぎていたので忌避した。でも、今はブームが終わった感じがするんで、気にせずに「オンラインサロン」と言えるようになったというのが1つ。もう1つは、ファンビジネスであることと啓蒙の側面のどちらを強く持っておくべきなのか悩んでいたんです。間を取るのが正解かなと思っていた時期もあるんですけど、ファンビジネスと啓蒙では需要も供給もだいぶ異なるものになります。これでは統制がつかないなということもあり、腹を決めてオンラインサロンにしました。

オンラインサロンにした以上、学びのあるものにしていく必要がありますが、それに対する自信はあるかもしれません。自分が知っている芸能における、今までの当たり前とこれからの当たり前とか。社会全体がだいぶ激しく移ろっている時代だと思います。そのときに、どういったマインド、どういったメンタリティーで、どういった行動を起こすと、どういったことが生まれていくのか。なぜそう言い切れるのか、そしてその先で自分が何をしようとしているのかっていうのをお話しし、コミュニケーションする場所を作ることによって、同じメンタリティーの方が増えていくと追い風が強くなっていくと思います。

アーティストやスタッフって0から1に火を起こす作業はできるんですが、やっぱり風が吹かないと起こした火が消えてしまうものです。風を最初に起こしてくれる存在は、絶対に必要および大事だと思っていましたから。そういった思想と言ってもいいんですけど、メンタリティー、マインドセットみたいなものを共有できる方を増やしていきたいという気持ちは、自分には強くあります。

———— BMSGにはアーティストごとにファンクラブがあって、それとは別にこの「B-Town」があるわけですが、中身としてはどんなことをされてるんですか？

いろいろありますが、1番最初に加入者を多く増やしたきっかけになったのは、パフォーマンス解説であったように思います。サッカーの試合とかを見ていると、ろくにサッカーもしたことないのにあいつ下手くそみたいな、ここで外すなんてどういう練習してんだ！みたいなのってあるじゃないですか。あれはアーティストでもあるあるで、特にオーディション番組だと、参加しているのはまだ素人の方々だから、見ている方もパフォーマンスに対して「ここが良かった」「ここが良くない」を言いやすいんですよね。実際にパフォーマンスの映像はYouTubeに切り出されているので、それを改めて見ながら「番組で自分はこういうことを言ったけれど、この部分のここが素晴らしい」と細かく解説するんです。このパフォーマンスをひたすら解説する作業が、最初に数字を伸ばすのに寄与したような気がします。

———— よくインスタライブのような動画配信もされていますね。

そうですね。これは主に、プロジェクトや制作の裏側の話をしていま続いていたと思うんですが、嘘がつけない時代であると思うので、実際に1つの仕事が行われたときに裏側ではどういうことが行われていたのかを、限りなくリアルタイムに近い形で、提供および共有できるのすね。芸能の仕事って、これまでは表に出たものが全てという時代ががB-TownのArchitectコースかなと思っています。基本的には自分のオンラインサロンではありますが、結局自分はBE:FIRSTの仕事もMAZZELの仕事もソロアーティストの仕事もトレーニー育成も見ているので、各種の裏側が見られるわけです。

———— 私も実はArchitectに加入していて、これは本当にBMSGという会社をブランディングしているんだなと思いながら拝見していますが、そういうことでしょうか。

それに近いと思います。会社自体のプレゼンスを高めるためです。起業当時、オーディション「THE FIRST」が始まって『スッキリ』(日テレ系)さんで放送されてたときって、毎週のように自分がどんな思いで会社を立ち上げてという映像が、30秒とか1分とか短い時間ですが放映されていたことはありました。いざ人気アーティストが誕生すると、その人気に人は吸い寄せられていくので、数字は伸びていきます。それと同時に、彼らや彼らが所属しているこのBMSGという会社の意識、思想、どこから来てどこへ向かうのかなどが共有されればされるほど、ただ単にはやっているから聴いているところから、それこそ人生を共有できるパートナーシップが生まれたりしていくと思いますし、彼らの活躍が単なるブームや一発屋といったものではなく、ムーブメントになって、カルチャーになっていくことにつながっていくと感じています。

人気アーティストを作ってお金を儲けたいみたいな気持ちははなからないんです。それよりも今、皆さんも感じていらっしゃると思うんですが、芸能界ってぐちゃぐちゃなんですよね。昭和平成にかけてもぐちゃぐちやだったし、今もまだずっと続いていて、それを完全に塗り替えたい。人が人と仕事をしている以上、ありとあらゆる問題が0というのは難しいと思うんですけど、それを確実に善性の高い方向に進めたい。何のためにかと言うと、あえて小学生みたいな言葉で言いますが、音楽を志している方々が夢と希望に向かって、明るく、仲良く、楽しく活動できる状況をまず作りたいですね。それを作れれば、結果、いいものが生まれる。やっぱりそれをやりたいので、不退転の思いです。

———— まさに「音楽ビジネス革命」そのものの気がしますね。そうした状況を作ることをファンの皆さんと一緒にやっていきたいのでしょうが、今後どのようにファンとの共創を進めていこうと考えていらっしゃいますか？

まず1つ補足させてください。先ほど言った「火を起こしても風が吹かないと大きくならない」みたいな話で言えば、今はファンの方の力が数字で可視化される時代にもなっています。よく経済系メディアで言われるようなファンダムの力、推し活の力みたいなことだと思いますし、それはすごくポジティブな側面としてあります。しかし一方で、ずっと続いている芸能界がぐちゃぐちゃな状態って、ファンの立場だった方に責任がないかというと、あると思うんですよね。悲しいことですが、確実に。アーティストの方の中には、精神的に芸能活動を続けることを選べなくなる方も少なくないと思いますが、その原因の大きいものとして、スタッフだったりファンの方だったりファン以外の方だったりとの関係があると思うんです。

そうしたことも考えないといけない状況が前提としてあったうえで、どういった形でファンの方々とご一緒していくのが美しいのかを考えると、今後も嘘がない打ち出しを続けるということしかないですし、そのためのアウトプットであったり、そのためのB-Townであったりにつながるかなという気がします。だから今回も、実は前回のテーマだった「嘘のないエンタテインメント」というものに帰結しているのかもしれません。

———— その「嘘のない」というSKY-HIさんのお考えはBMSGに所属する皆さんに伝わっていて、どんな映像を見てもお話を伺っても、響いてきます。きちんとビジョンを社員や所属アーティストに伝えて、その方たちが実行していくっていうのは非常に大変なことだと思いますが、どのように説明し、腹落ちさせているのですか。

どう考えているのかを伝える機会は少なくないですし、何より自分のステージをアーティストは見ていたりもするので、提案、実践、フィードバックみたいなことはこまめにできているとは思います。これはスタートアップ企業の強みだと思うんですけど、そもそもスタート段階で強いミッションなりビジョンを掲げて、それにフィールした方だけがオーディションを受けてくれていることはあると思います。

いろんなオーディションがあり、いろんな芸能事務所があるなかで、当時うちのオーディションを受けてくれてる方々です。しかも、今でこそ目に見えた数字を残していますが、当時は1芸能人ですよ。それが実家からの配信で「会社を作ってオーディションやります」って言っても、うまくいかなそうじゃないですか(笑)。あれに何か感じてくれるタイプの方っていうのは、やっぱりもともとそういう素養の強かった方がそもそも集まってきてくれたというのがありますよね。

———— 今後の「音楽ビジネス革命」は、どう展開していきますか？

最初に自腹で1億円以上使ってオーディションを立ち上げ、そこで得たのは信頼です。それがクラウドファンディングの4億5000万円になった。次はまたその4億5000万円を全部掛けたら、それが10億円になる。次にその10億円を全部掛けて、20億円になる・・・っていうのが今のフェーズなんですが、今、また投資したいものが見つかってはいて。2つあるかなという気がしています。1つは現存のアーティストに対するもの。自分を含めてファンの方が、アーティストのファンをやっていて楽しくなる展開に投資していきたい。そして、もう1つが育成です。ワードにするとそんな大したことなかったですね(笑)。

3つ目のグループの予定も当然あるんですが、やっぱりすごいことにはしたいので、リーチを最大に増やすためには、今のBMSGならどういう方法が取れるかを考えたいですね。とはいえ、今年MAZZELがデビューしたばかりで、まだ3つ目のデビューがいつ頃かというタイミングでは当然ないです。同時に言うと、デビュー前の時期というのは、失敗ができる唯一の時期なわけじゃないですか。なので、トライはいろいろしていきたいなとは思っています。例えば楽曲を作ってみて「ちよっと違うかな」と思ったらリリースしなければいいだけの話。トレーニ一だから「最近リリースないね」とも言われるわけではありませんし。だから、何でもやってみればいいと思っています。

———— もう1つ、BMSGの描く将来像には「世界」というワードもあります。

そうですね。動線は割と明確にありますし、そのために必要なことも見えてはいるので、そこはしっかりとやっていく予定です。相当大変ですけどね。アメリカ在住のスタッフがいるんですが、エリアを分けたときに、アメリカから見ると、東南アジア、東アジア、日本となり、日本は東アジアの1国というよりは、良くも悪くもですが、カルチャーも政治背景も流行も分断しすぎていてガラパゴスの極地なんです。日本で何か物を売ろうと思ったら日本用にしないといけない。そういう意味で、日本への輸出に手こずっている海外も少なくはないと思います。K-POPにしても、韓国語曲で米Billboardの1位が取れるのに、日本市場だけは日本語歌詞を歌って、「日本デビュー」というものが存在している。そうやって、日本で売るときは日本語にしないといけないことが割と象徴的な気がします。逆に、日本発で世界的にヒットするのは、YOASOBIの『アイドル』みたいな楽曲です。僕はあの曲が大好きなんですが、文脈的にはアニメおよびアニソンみたいなところの強みなのかなと思います。海外の人と会って「日本の音楽です」と自己紹介しても、「何のアニメの主題歌ですか？」と返ってくる時代ですから。

でも動線は見えました。今年に入ってから「これだ」っていうのが思い浮かんだので、今年、来年にトライして、20年代中頃に何か明確な実績が生まれればいいなと思っています。

———— 最後に「BMSG FES'23」について。今年はどんなフェスになりそうですか？

結局、ライブエンタテインメントを作るうえで成長させたい部門は、もう無数にあるわけです。今回はライブ収録、つまり映像技術の向上を図りたいため、会場が屋内である必要がありました。同時に、つい先日、「BMSG EAST」と「BMSG WEST」という追加アーティストを発表しました。全アーティストを出身地で2つに分けたんです。なんか遊びたいんですよね、どうしても。1年目の「BMSG FES」では「THE FIRST」からのBE:FIRSTとソロアーティストらの強い絆を発露させ、そこにNovelCoreもいて。2年目の今年は新しくMAZZELという仲間ができ、トレーニーを含めて新たに8人が「BMSG FES」に入ってきます。そうなると全員で作りたいじゃないですか、本気の文化祭を(笑)。才能あふれる人間たちが集まった本気の文化祭をやり続けます。それで、やっぱり楽しいんですよ。文化祭前に夜に学校で居残り作業とかしてると仲良くなったりするじゃないですか。そういうことが生まれるんです。

あと何が面白いって、バックボーンが違いそうな人が一緒なのが面白いですよね。実際にリアルな学校での文化祭の手伝いとかになると、率先してやりそうなタイプに、やらなそうなタイプ、準備することを知らされてないタイプ、むしろ企画立ててやっていくタイプとか。いろんな人が集まってやれているのはなぜかって言ったら、みんな音楽が好きで、その音楽に基づいた企画ができているからだと思います。

## 音乐商业革命续篇：“无法说谎的时代”，如何与粉丝相处

**2023年7月20日，SKY-HI（日高光启）登台参加日经Cross Trend FORUM 2023，演讲主题为“音乐商业革命续篇——‘无法说谎的时代’，如何与粉丝相处”。在2022年的同一论坛上，他曾表示：“在当今时代，走红不可或缺的条件就是‘没有谎言’。”这次，我们请他谈了谈如何与粉丝相处。（提问者：吾妻拓，《日经Cross Trend》编辑委员）**

——5月，我在东京代代木第一体育馆观看了您的SKY-HI ARENA TOUR 2023 -BOSSDOM-演出。整场演出的舞台编排和制作几乎无可挑剔，气势也十分震撼，我带着满心感动踏上归途。MC中，有一句话尤其令我难忘，就是您那句“BMSG要和你们一起改变时代”的宣言。那股力量甚至让我起了鸡皮疙瘩。其中，“和你们一起”尤其体现了您的理念。对身为艺人的您和身为社长的您来说，粉丝分别是怎样的存在？

谈到这类话题，尤其是商业媒体，往往会把重点放在“粉丝群体的力量”上。从商业角度看，这没有错，但说实话，我觉得其中也有一些误导。现在确实是一个“粉丝能够主动推动数字增长的时代”。但为此该做的，并不是哪里有“需求”、哪里有“市场”，就朝哪里投石。人们觉得“非这位艺人不可”的理由，恐怕有多少人，就有多少种。但仅凭音乐好、唱得好、跳得好，还不足以构成这样的理由；反过来，只有人格魅力也不够。无论作为艺人，还是作为社长，我对旗下艺人的要求都是两者兼备。我认为，缺了哪一项都绝对不行。

人们喜欢上一位艺人、偶像或演艺人士，觉得“非这个人不可”的契机，想必也因人而异。但对我们来说，越是仗着这份喜爱而敷衍工作，音乐文化和整个音乐圈就越会失去力量，最终走向衰败，氛围也会变得冷漠紧张。尤其在今后的时代，艺人和偶像必须承担起引导粉丝的责任。一方是“实际推动数字增长的粉丝”，另一方是“有能力令人觉得非他不可的艺人”，两者之间的相互作用不可或缺。艺人在做的事，粉丝当然做不到；同样，粉丝在做的事，艺人也绝对做不到。所以我认为，双方应该认真建立关系，不能把对方的付出视为理所当然。

——现场演出就是引导粉丝的一个典型场合。您以前说过：“艺人与粉丝最恰当的见面方式，就是通过现场演出的舞台。”听BMSG旗下艺人的MC，我总觉得，他们都在以一个人的身份，努力向粉丝传达自己的心声。

没错，我觉得这对双方建立“健康的关系”至关重要。不是有句话叫“有粉丝才有偶像”吗？我觉得这种说法对哪一方都没有好处。首先，如果唯一的目标就是取悦粉丝，就会偏离艺人自身的创作意愿。艺术和表演，本来都源于自我表达：“我想这样表达”“我想这样呈现音乐”“我想创作这样的歌，以这样的身份站上舞台”。一味取悦粉丝，就会与这些心愿渐行渐远。即使在舞台上，比起一丝不苟地完成表演，与粉丝对视、挥手，似乎更容易迅速带动现场气氛，得到回应的人当然也会高兴。我知道这种互动很重要，同时也有很强的破坏力。正因如此，一旦双方都依赖这些互动，形成失衡的关系，彼此对音乐的热情就会逐渐淡去。如果粉丝看演出只是为了等艺人向自己挥手，而艺人最重要的任务也变成了挥手，大家应该能想象，有些东西就会逐渐淡化、动摇。艺人如果把“挥挥手就能带动气氛”当作成功经验，甚至形成了身体记忆，就容易不再与每一个人真诚交流，而是笼统地把台下的人看成“粉丝们”。“粉丝们”这个说法，其实有些简单粗暴。每个人寄托在艺人身上的感情、投入的金钱，以及支持的年数，都不一样。我觉得，试着理解每个人的心情，是艺人对到场观众最起码的礼貌。有了这份心意，才可能把每个人当作独立的个体，认真面对，表达感谢。这一点绝对不可缺少。或许更接近礼节吧，但说到底，也就是这么回事。

——也就是说，要体会粉丝的心情，真心实意地传达自己的想法。那么，您如何寻找与他们产生共鸣的契合点？

这与我上一次登台演讲，也就是2022年谈到的内容有关。只要做到“不说谎地沟通”，自己的表达与粉丝的共鸣点就会有不少交集，而且越是核心粉丝，交集就越多。再就是顺着现场高涨的情绪，把自己平时强烈感受到、深信不疑的东西，更有力、更直接地表达出来，我想，这最终就会带来共鸣。脱去言语和内心的外衣，是艺人应尽的责任。

现在，人们的需求越来越多元，对艺人来说，这是件好事。我觉得，其中很重要的一点就是“可以不必说谎”。比如，既然是偶像就必须这样做，必须穿统一的服装、时刻保持笑容，不能显露难受的一面——这些观念，大概到平成末期就已经统统抛到脑后了。在如今这个时代，平时只要不说谎，如实表达自己是怎样的人，共鸣应该就会自然而然地产生。比如，明明是杏鲍菇，一上舞台却得假装自己是牛肉，这样的时代确实持续了很久。但现在，“杏鲍菇做杏鲍菇就好”。掩饰自己、装成别的样子，相当辛苦。即便费尽心思假扮牛肉，大家还是多少能看出来：“那家伙不是牛肉，是豆制肉吧？”这样一来，个人的数据也很难增长。现在这个时代，即使自以为伪装得很好，大家也能识破。

——真诚的表达不断带来共鸣，而承接这份共鸣的地方之一，就是BMSG运营的线上会员社区B-Town。这里聚集着核心粉丝，以及深深认同您理念的粉丝。月费5000日元的Architect会员方案，已有超过1万名会员。以前，您把它称为“具有线上会员社区性质的粉丝社区”，如今则直接称为“线上会员社区”。这两种定位有什么区别？

主要有两点。刚创业时，线上会员社区带起的风潮有些过于偏向新自由主义，所以我避开了这个称呼。不过现在感觉热潮已经过去，可以不再顾虑，直接称它为“线上会员社区”了。这是第一点。第二点是，我一直在犹豫，究竟应该更侧重粉丝业务，还是更侧重启发和引导。有一段时间，我觉得或许应该在两者之间寻找平衡。但粉丝业务与启发引导，无论需求还是供给，差别都很大。这样下去很难统一方向，所以我下定决心，把它定位为线上会员社区。

既然定位为线上会员社区，就必须提供值得学习的内容。在这方面，我或许还是有些信心的。比如，我所了解的演艺行业，过去有哪些惯例，今后又会有哪些新常态。如今，整个社会都在经历剧烈变化。在这样的时代，以怎样的想法和心态采取怎样的行动，会产生怎样的结果？为什么我能如此断言？接下来，我又打算做什么？我想建立一个空间，谈论这些问题，与大家交流。拥有相同心态的人越来越多，支持我们的顺风也会越来越强。

艺人和工作人员能从无到有，点起一簇火，但如果没有风，点起的火还是会熄灭。我一直觉得，最先带来那阵风的人不可或缺，也非常重要。所以，我很希望有更多人认同并分享这种思想——也可以说，是这样的心态和思维方式。

——BMSG旗下艺人各有自己的粉丝俱乐部，除此之外，还有B-Town。那么，B-Town具体提供哪些内容？

内容有很多，但我觉得，最初带动会员人数大幅增长的是表演解说。看足球比赛时，不是经常有人自己都没怎么踢过球，却说“那家伙踢得真差”“这都踢不进，平时到底怎么练的”吗？艺人也经常遇到这种情况。尤其在选秀节目里，参赛者还都是非专业人士，观众就更容易评价他们的表演，说“这里好”“这里不好”。节目中的表演片段会单独上传到YouTube，我就一边重新观看，一边详细解释：“节目里我当时是这样说的，具体到这一段，这个地方特别出色。”我觉得，持续做这样的细致解说，对最初的会员增长起了很大作用。

——您也经常通过Instagram直播等形式分享视频内容。

是的，主要讲项目和制作的幕后故事。过去很长一段时间，演艺工作呈现在公众面前的内容，就是大家所能看到的全部。但我觉得，现在是一个无法说谎的时代。一项工作实际开展时，幕后究竟发生了什么？B-Town的Architect会员方案，就是尽可能接近实时地提供、分享这些内容。它基本上是我个人的线上会员社区，但BE:FIRST、MAZZEL、个人艺人的工作，以及练习生的培养，都在我的工作范围内，所以大家能看到各类工作的幕后情况。

——其实我也是Architect会员。观看这些内容时，我觉得，这确实是在塑造BMSG的公司品牌形象。可以这样理解吗？

差不多是这个意思，就是为了提升公司本身的影响力。创业初期，选秀THE FIRST启动，在日本电视台系列频道的《Sukkiri》播出时，几乎每周都会播放一小段影像，介绍我是怀着怎样的想法创办这家公司的。虽然只有30秒或1分钟，但确实有这样的内容。一旦出现人气艺人，大家就会慕名而来，数字也会随之增长。与此同时，大家越了解艺人和他们所在的BMSG，越了解我们的想法、理念，以及我们从何而来、要往哪里去，就越有可能从“因为流行才来听”，发展出能够分享人生的伙伴关系。我觉得，正是这样，他们才不会只掀起一阵热潮、昙花一现，而是能够带起一股潮流，逐渐形成文化。

我从一开始就没有过“打造人气艺人来赚钱”的想法。比起这个，我更在意的是，演艺圈现在很混乱，我想大家也都感受到了。从昭和到平成一直如此，这种状态至今仍在延续，我想彻底改变它。只要是人与人一起工作，就很难杜绝所有问题，但我希望切实推动这个行业朝更有善意的方向发展。为了什么呢？我刻意用小学生般简单的话来说，就是想先创造一个环境，有志于音乐的人可以朝着梦想和希望，开开心心、和和睦睦地做音乐。有了这样的环境，自然就能诞生好的作品。这才是我想做的事，所以绝不会退缩。

——这正是“音乐商业革命”。您希望与粉丝一起创造这样的环境，那么，今后打算如何推进与粉丝的共创？

我先补充一点。就像刚才说的，“点起了火，没有风也烧不旺”，如今，粉丝的力量也能通过数字清晰地呈现出来。这应该就是商业媒体常说的“粉丝群体的力量”“追星活动的力量”，确实有非常积极的一面。但另一方面，面对演艺圈长久以来的混乱，粉丝是否完全没有责任？我认为并非如此。很遗憾，但确实也有责任。我想，不少艺人因为精神上难以承受，无法再选择继续演艺活动。其中一个重要原因，就是他们与工作人员、粉丝，以及粉丝以外的人之间的关系。

这些问题同样需要认真考虑。在这个前提下，再去想怎样与粉丝同行才是理想的关系，我觉得，唯一能做的就是继续坚持真实、不虚假的表达。我们的内容创作，以及B-Town，也都是为此而存在的。所以，这次的话题或许最终还是回到了上一次的主题——“没有谎言的娱乐”。

——您所说的“没有谎言”，已经传达给BMSG的每一位成员。无论看他们的影像，还是听他们谈话，都能感受到这一点。把愿景清楚地传达给员工和旗下艺人，再由他们付诸实践，是非常不容易的。您如何向大家解释，帮助他们真正理解并认同？

我有不少机会向大家传达自己的想法。更重要的是，艺人们也会看我的舞台，所以提出想法、付诸实践、交流反馈，这样的过程应该进行得相当频繁。我觉得，这也是创业公司的优势：从一开始就提出明确而坚定的使命或愿景，来参加选秀的，也都是对此产生了共鸣的人。

当时有那么多选秀、那么多经纪公司，他们却选择了我们。而且，虽然我们现在已经取得了看得见的成绩，但当时的我也不过是一名艺人。这样一个人，在父母家里开直播，说“我要成立公司、办选秀”，怎么看都像是不太能成吧（笑）。能从这件事里感受到什么的人，本来就比较具备这样的特质。可以说，最初聚集过来的就是这样一群人。

——今后的“音乐商业革命”将如何展开？

最初，我自掏腰包，投入超过1亿日元办选秀，由此获得了信任。这份信任又转化为4.5亿日元的众筹资金。接下来，再把这4.5亿日元全部投入，变成10亿日元；再把10亿日元全部投入，变成20亿日元……我们现在正处于这样的阶段。如今，我又找到了想继续投资的方向，大概有两个。一个是现有艺人的发展。我想投资一些新安排，为粉丝增添支持艺人的乐趣，也包括我自己的粉丝。另一个就是人才培养。说出来，好像也没什么了不起的（笑）。

当然，我们也有推出第三个组合的计划。不过，既然要做，就希望做得非常出色。所以我想考虑，以现在的BMSG，能用什么方法触达尽可能多的人。话虽如此，MAZZEL今年才刚出道，当然还没到谈第三个组合何时出道的时候。另一方面，出道前不也正是唯一可以失败的时期吗？所以，我想多做些尝试。比如，先做一首歌，如果觉得“好像不太对”，那不发行就好了。毕竟还是练习生，也不会有人说“最近怎么没发作品啊”。所以我觉得，什么都可以试试看。

——此外，BMSG描绘的未来图景中，还有“世界”这个关键词。

是的。我们已经有了比较清晰的路径，也看到了为此需要做的事，接下来会扎实推进。当然，难度相当大。我们有工作人员常驻美国。从美国的视角划分地区，会分成东南亚、东亚和日本。也就是说，日本与其说是东亚的一个国家，不如说，无论好坏，它在文化、政治背景和流行趋势上都与其他地方相隔太远，“加拉帕戈斯化”到了极致。（编者注：“加拉帕戈斯化”指产品或文化等在相对独立的环境中形成独特发展路径，与外部市场或环境产生明显差异。）想在日本卖东西，就得专门针对日本市场调整。从这个意义上说，不少海外业者向日本输出产品或内容时，应该都颇费周折。即便是K-POP，凭韩语歌曲就能登上美国Billboard榜单第一，但唯独在日本市场，还要唱日语歌词，还存在“日本出道”这回事。在日本销售就得改用日语，我觉得这很有代表性。反过来，从日本走向世界、取得全球性成功的，是YOASOBI的《偶像》这样的歌曲。我非常喜欢这首歌。不过，从它传播的背景来看，我觉得，发挥作用的或许还是动画和动画歌曲的优势。毕竟，如今向海外人士介绍自己，说“我是做日本音乐的”，对方会问：“是哪部动画的主题曲？”

不过，路径已经看清了。今年以来，我想到了一个方向，觉得“就是这个”。所以打算在今年、明年做些尝试，希望能在本世纪20年代中期取得一些明确的成果。

——最后想请您谈谈BMSG FES'23。今年会是一场怎样的音乐节？

说到底，制作现场娱乐演出，我们希望提升的环节有很多。这次想加强的是现场录制，也就是提升影像技术，因此必须选择室内场馆。同时，就在前几天，我们公布了新增的演出阵容：BMSG EAST队和BMSG WEST队，按出身地把所有艺人分成两队。我就是想和大家一起玩点什么，实在忍不住。第一年的BMSG FES，展现了BE:FIRST与个人艺人从THE FIRST一路走来结下的深厚情谊，Novel Core也参与其中。今年是第二年，我们迎来了MAZZEL这群新伙伴，连同练习生，共有8人首次参加BMSG FES。这样一来，就想和大家一起认认真真地办场文化祭，不是吗（笑）？（编者注：文化祭是日本学校常见的校园文化活动，通常由学生策划演出、展览等。）我们要聚起这些才华横溢的人，把这样的文化祭认认真真地一直办下去。而且，确实很开心。文化祭开始前，大家晚上留在学校一起做准备，不就会慢慢熟络起来吗？这里也会发生这样的事。

还有一个有意思的地方，就是成长背景看起来各不相同的人聚在了一起。假如真是在学校帮忙筹备文化祭，有的人像是会主动带头干的，有的人像是不太会参与的，有的人可能连要做准备都没人通知，还有的人则会自己策划、组织大家一起做。为什么这么多不同的人能聚在一起完成这件事？我想，是因为大家都喜欢音乐，而我们策划的活动，正是以音乐为基础的。
